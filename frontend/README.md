# 开放工作台正文保存与恢复

正文保存仍通过本机 Mapping API 和 SQLite。停止输入 400ms 后保存，连续输入最多等待 2s；未结束的 IME 组合不拆分。正文编辑动作以 1s 间隔及选区、输入类型、粘贴、格式、焦点和切卡边界分组，保存批次不等同于撤销步骤。当前入口使用单文本块；完整多块编辑界面由后续正文工单扩展，离开当前编辑区先结束组并提交原卡。

`draft-recovery.ts` 把未确认草稿、结束的动作组和未知结果的原请求保存在浏览器本机 `localStorage`，以编辑会话、项目、卡片隔离。它不是权威正文库，也不进入 40 步操作历史。恢复依赖同一浏览器资料和同一服务源地址；清除浏览器存储、切换资料或端口不会自动迁移这些记录，不承诺崩溃前最后一次按键必定落盘。浏览器容量不足时保留内存输入并明确显示恢复失败。

重开只展示恢复入口，不自动写入。明确恢复先向受鉴权的 `/api/mapping/projects/:id/cards/:cardId/identity` 查询原身份，再以原版本提交。损坏条目保留原文并隔离；已删除身份不能直接恢复正文，撤销删除仍检查绑定动作。恢复任务在每次网络等待后核对任务、编辑对象及 generation；期间继续输入、切卡、切项目或关闭面板会保留原恢复记录，要求重新明确选择。晚到的旧恢复任务不能接管后发任务。旧 ACK 只确认与请求绑定的原项目、原卡、字段、输入和 generation；未知结果保留原 commandId、expected 和请求；明确校验拒绝后允许修正并提交最新草稿。

仅在 pending 或 closed 中保留的输入遇到保存失败时，也先成为可见、可编辑和可恢复的当前草稿。明确拒绝只有在该输入仍被保留，或已有后来完整输入替代时才移出旧批次；失败响应不会把旧稿覆盖到后来输入。未知结果仍保留原请求等待明确重试。重开检测到当前项目的合法恢复稿时显示“有待恢复的未确认草稿”，不把尚未执行或被拒绝的输入显示为已保存。

冲突同时展示本机与已保存内容，选择时再次核对远端版本，并先持久保存另一份可恢复副本；副本写入失败就停止选择。之后的写入仍受服务端版本校验，不能用重读结果静默覆盖并发修改。

`body.edit.payload.requiredAssetIds` 是媒体保存门槛。当前 Mapping 尚无已验证的媒体持久化通道，非空引用返回 `MEDIA_NOT_PERSISTED`，不写版本、历史或保存回执。媒体拒绝后的同 generation 重试保持原请求；新 generation、恢复副本和重开后的草稿继续保存所需资源身份，不因重建 command 而剥离引用。#16 接入真实资源后扩展该门槛及媒体界面；这里没有模拟“已保存”资源。

恢复记录中的原正文请求必须覆盖该 generation 草稿声明的全部资源身份；允许原请求更严格、集合顺序不同，以及旧 schema 1 只在 command 中保存资源要求。缺省或缺少要求的原请求、标题请求夹带正文资源字段属于损坏记录，整条隔离并保留原字节，不补写或重建原幂等请求。身份、正文、expected 与有效 generation 的校验继续保留。存在损坏原件时显示“部分恢复记录未确认”，不会因其它合法草稿的保存 ACK 清除损坏提示；合法恢复仍独立执行。

测试使用随机回环端口、自有临时 SQLite 和全新浏览器上下文；合成 composition、格式及粘贴事件只验证事件协调，不代表真实系统输入法、富文本编辑或系统剪贴板验收。

同一 journal 的同项目／卡片／字段／generation 必须对应同一文本、expected 和原请求；不一致的投影整条隔离、保留原字节。commandId 在 journal 内也只能绑定一份完整请求，不能跨 generation 改 payload 后沿用旧键。合法 pending／drafts／closed 重复投影仍可恢复；缺少 command 的投影共享已存在的原请求，尚未生成请求时共享该输入的资源要求和首次生成的请求。仅真正缺省的 command 表示尚未生成，非法占位不能被补成合法请求。ACK 按完整目标、输入和原请求消费，不按 generation 数字清除其它字段或卡片；已生成请求的 expected 不因另一条 ACK 改写。

编辑协调器按项目／卡片／字段只持有一个逻辑 active 草稿，`drafts` 中同字段不能同时声明不同 generation；这种坏 shape 整条隔离并保留原字节，不按数组顺序覆盖或排序选取。相同 generation 的一致投影仍兼容；`closed`／`pending` 的前代请求与最新 active 可以共存，未知原请求确认后才按其回执提交最新输入。

## 自由放卡、选择和几何

卡片工具先等待画布落点（也可落在旧卡上），再就地输入标题。Enter 完成、Shift+Enter 换行、Esc/外部点击保留；空标题仅显示未命名占位。菜单“编辑标题”和标题双击同入口；正文双击保留当前单文本块入口。创建与连续首次标题一步，已有标题每轮一步，输入内原生逐步 undo/redo 不同时撤销项目。固定编辑轮次的 textarea defaultValue 保留原生输入历史，实际保存仍由同一草稿协调器负责。

选择工具空白拖动完整包含框选，普通框选替换，Shift 追加。任一已选卡整体移动，保持相对位置；单选尺寸手柄允许覆盖邻卡。默认对齐吸附可见开关，6 屏幕像素接近边/中心时吸附；Alt 拖动暂禁、松开恢复开关。键位及开关仅当前 UI 会话属于工程选项。移动工具或 Space 临时平移、缩放只改视口。

多卡几何通过 pose.batch 原子保存，一次 revision/历史；单卡普通移动兼容 pose.move。预览与取消不写权威状态，失败原请求可重试，正文/Pose 版本分开。选区与临时置前仅属于 UI；持久次序仍是明确的 creation_ordinal，未实现四类共同 StackOrder。未来搜索复用同一选区路径，本票不实现搜索或后续完整写字板。合同见 [ADR0024](../docs/adr/0024-free-card-geometry.md)。
