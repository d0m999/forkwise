一 先从这里开始

本包供品牌方、设计师、开发者及受托制作供应商使用。使用前先阅读 04-spec 中的规范，再按场景选择 01-logos 或 02-icons 中的正式素材；具体使用边界见 LICENSE-usage.txt。

本次定稿保留 A 方案的几何字标。字标以 Outfit 550 字重为基础，经过手工成对字距调整，正式字标均已转为路径，显示和输出时不需要安装字体。请直接使用交付字标，不要重新键入 forkwise 替代。

二 文件目录与用途

01-logos/  13 件
正式 Logo 资产，用于品牌组合标志、字标及不同背景和输出方式。优先使用矢量文件缩放制作；按具体背景选择彩色、单色或反白版本。

02-icons/  5 件
独立图标、网站小图标及通用 App 图标素材。App 母版用于后续平台适配，正式上架前仍须核对目标平台当时的尺寸、裁切、安全区及格式要求。

03-color/  2 件
品牌配色及可复用色值，供屏幕设计和制作沟通使用。CMYK 数值仅为数学近似，未经过 ICC 校准。

04-spec/  3 件
品牌使用规范与制作参考，说明组合关系、安全空间、最小尺寸和不当使用等要求。quick-spec.html 为离线阅读嵌入了中文字体子集，字体许可随根目录 LICENSE-usage.txt 提供。

05-test/  1 件
小尺寸与识别测试参考。请按实际显示尺寸检查，不以放大预览代替终端检查。

根目录  2 件

合计：13 + 5 + 2 + 3 + 1 + 2 = 26 件。不附 ZIP 压缩包。

三 品牌色与制作边界

主杏橙  Apricot  #F3AC64  RGB 243 / 172 / 100
结构深棕  Brown  #623C2A  RGB 98 / 60 / 42
背景奶油  Cream  #FFF8EF  RGB 255 / 248 / 239

以上为 sRGB 屏幕色值。印刷时请让供应商按目标纸张、油墨、设备和 ICC 配置进行转换与打样。包内 CMYK 是数学近似值，不代表已校准的印刷配方，也不构成专色或颜色一致性认证。

保持正式素材的比例、几何形状、表情和字距，不要自行拉伸、重排、描边或添加阴影、渐变等效果。安全空间和最小尺寸以 04-spec 为准。

16 px 只以整体轮廓和品牌识别为目标，不保证能稳定辨认眼睛与表情细节。使用小尺寸适配素材，并在目标设备、浏览器或应用中检查实际效果；空间允许时优先使用更大尺寸。

App 图标为通用母版，未获得所有平台的认证或逐平台审核。平台裁切、系统遮罩和上架规则可能变化，交付不代替平台适配与上线验收。

本包为 T1 基础设计交付，不单独附可安装字体；规范 HTML 嵌入中文阅读用的 Noto Sans CJK SC 字体 WOFF 子集，不用于品牌字标。品牌字标仍为路径，对字体文件无显示依赖。Outfit 与 Noto 的来源、版权及 SIL Open Font License 1.1 信息见 LICENSE-usage.txt。本次未进行商标近似检索、注册可用性判断或法律审查，不应使用本包暗示商标已注册。
