# 见岔（Forkwise）· 开放画布原型

2026-10-11，全新独立前端原型。依据远端 `d0m999/forkwise` 默认分支 `codex/local-delivery`，commit `10db5957c82ff3905c1e292f7da148a43050ab39` 的 `docs/design-interview.md`，最新 D423。

本目录为独立静态原型源码，不接入生产后端，不读取或迁移旧用户存档。所有预置文字都是界面演示，不是投资研究结论。品牌复用仓库 Forkwise32 refined A 的杏色章鱼。

## 启动

从仓库根目录运行：

```sh
python3 -m http.server 48931 --bind 127.0.0.1 --directory prototype/open-canvas-20261011
```

打开 `http://127.0.0.1:48931/`。无需安装依赖、构建或登录。服务只绑定本机，不是公网网站。

内容保存在当前浏览器与访问地址对应的 localStorage；换地址、端口、浏览器不会自动迁移。项目菜单可导出 Markdown 和完整项目 JSON。私有浏览、清理站点数据或浏览器存储故障会影响保存，请导出保留重要试用内容。

## 设计方向

克制的纸面工作台：暖灰点阵画布、白色内容、杏色标题区域，紧凑顶部项目页签与底部创作工具。右侧写字板专注完整正文，搜索为独立居中窗口，避免把阅读预览变成画布操作。颜色与品牌来自基本品牌包；其余中性色仅服务信息层级。图标采用 Lucide 基础 SVG 轮廓；中文系统无衬线字体，无外部字体请求。

Taste 的层级、留白、克制配色、状态与响应式检查适用于此密集工具；没有套用营销网站的装饰性版式、强动画或无关功能。

## 已落入原型的范围

- 项目切换、新建、重命名；独立浏览器保存；修改统一撤销/重做
- 卡片放置、标题、可重叠布局、移动和调整尺寸
- 右侧写字板：所见即所得正文、按需格式菜单、标题/列表/图片、块顺序、自动保存、展开/还原
- 自定义标签及当前项目卡片搜索，关键词与标签交集，只读预览与明确打开画布分离
- 五种形状、独立文字、图片、画笔与荧光笔、普通连线、组合与分区
- 图片裁剪预览/完成/取消、恢复原图、90°旋转和大图查看
- 普通连线可选择直线/折线/曲线；连线不建立领域推导，不触发AI
- AI 工具只提供明确标注的本地模拟候选，点击明确添加才产生新卡；没有真实模型或公开资料查证

## 不能当成生产验收的部分

这是可操作原型，不是生产引擎重选或全量 D01–D423 实现。搜索中文分词暂用浏览器 Intl.Segmenter，未接入 jieba 专业词典、OpenCC 简繁等价；匹配说明中明确披露。大型文档、复杂嵌套列表、外部剪贴板跨应用兼容、性能与所有辅助技术尚未全面验证。裁剪、层级、跨项目剪切等复杂边界需以本轮检查记录为准，不把代码存在等同验证完成。

暂不接后台、SQLite、真实AI、账户、发布服务或旧研究工具。
