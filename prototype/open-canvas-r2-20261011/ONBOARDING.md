# Forkwise 上下文引导

> 引导源码与测试已按原冻结哈希恢复；下述历史浏览器结果保留为参考，恢复版需以本轮新 QA 为准。

2026-10-11。独立、无框架的开放画布入门层，沿用暖纸白与杏色界面。引导只读取可见 DOM，不读取项目对象，也不调用 `FW`、`FWPanels`、`FWCanvas` 或剪贴板 API。

## 集成

1. 在现有样式之后引入 `onboarding.css`。
2. 在应用脚本之后引入 `onboarding.js`。
3. 在 `FW.boot(); FWObjects.init(); FWClipboard.init();` 之后调用 `FWOnboarding.mount()`。
4. 使用说明中的「重新查看新手引导」按钮先关闭当前说明弹层，再调用 `FWOnboarding.start()`。不要让两个弹层同时抢焦点。

```html
<link rel="stylesheet" href="onboarding.css">
<script src="onboarding.js"></script>
<script>
  FW.boot();
  FWObjects.init();
  FWClipboard.init();
  FWOnboarding.mount();
</script>
```

此模块不自动启动；重复调用 `mount()` 不会创建重复 DOM 或监听器。引导不使用 `role="dialog"`、`aria-modal` 或背景遮罩，不会触发现有应用的模态快捷键守卫。

## 公共接口

- `FWOnboarding.mount({autoInvite: true})`：幂等初始化；默认首次只显示邀请，不抢焦点。传 `false` 可只注册帮助入口，不显示邀请
- `FWOnboarding.start()`：用户主动从第 1 步重新开始，并把焦点放在引导标题。尚未 mount 时自动初始化
- `FWOnboarding.dismiss()`：关闭并记住跳过状态；已完成状态不会被改回跳过
- `FWOnboarding.getState()`：返回只读快照：`status / step / view / compact / suspended / storageAvailable / persistent`，用于集成检查，不暴露项目内容

## 四步内容与真实目标

| 步骤 | 目标 | 说明 |
| --- | --- | --- |
| 建卡 | `#toolDock [data-tool="card"]` | 点击工具，再点空白处放卡；输入标题，Enter 完成 |
| 正文 | 可见 `#fp-body`；否则优先选中卡片；再否则可见卡片；空画布回指建卡入口 | 双击打开正文；提供空画布说明，不创建示例卡 |
| 普通连线 | `#toolDock [data-tool="line"]` | 对象/空白之间拖动；不建立推导关系，不触发 AI |
| 搜索 | `#search` | 当前项目标题与全文、标签；只读预览与明确定位区分 |

「下一步」与箭头键只切换导览说明；不会造数据、切换工具、打开编辑器、移动画布或发起搜索。「定位到区域」只移动键盘焦点，不点击控件。对于尚无键盘入口的卡片容器，焦点落到现有 `#canvasEngine`，不修改卡片 tabindex。

每步与邀请都明确写明 AI 仅本地模拟、未连接模型、不联网查证。没有后端请求、模型请求、账号、上传或外部依赖。

## 可中断与焦点规则

- 点击画布或工具，导览收为可恢复小条；应用事件继续执行，不拦截用户实际创作
- 输入框或正文得到焦点时，活动导览收起，不替换用户正文、不改变选区
- 首次邀请在已有输入焦点或已开写字板时暂不显示；关闭编辑后再显示，不主动聚焦
- 搜索、AI、帮助、项目对话框、图片查看、插入菜单、工具 popover、裁剪和保存异常提示出现时，导览暂时隐藏，保留步骤，不建立第二套焦点陷阱
- 引导内 Escape 关闭；左右箭头切步骤；Tab 按浏览器原生顺序离开，不圈住用户
- 引导拥有焦点时，在 window capture 阶段截断应用快捷键，防止 N、Delete、Ctrl/⌘ Z、Ctrl/⌘ D、Ctrl/⌘ K、Space 等影响画布
- 引导内 copy/cut/paste 不冒泡给应用剪贴板；复制选中的说明文字可按原生浏览器行为进行
- 关闭时仅在焦点原本属于引导的情况下返回上个有效应用控件；不夺走正在编辑正文或模态窗口的焦点
- 缩小时可点「继续引导」恢复；每个视图都有关闭入口
- 高亮层不接收鼠标事件；无灰幕、无自动滚动；窄屏与短屏卡片限制在视口内，可独立滚动；尊重减少动态效果设置

## 持久化与刷新

仅写入独立 key：`forkwise.onboarding.open-canvas.r2.v1`。

值仅包含 `{version:1,status,step}`，没有项目 ID、卡片内容、用户输入或搜索词。

- 首次邀请不写状态
- 开始/切步记住 `active` 与最后一步；刷新后只邀约续看，不自动恢复遮挡与焦点
- 跳过记住 `skipped`；刷新不再邀约
- 完成记住 `completed`；刷新不再邀约，帮助入口随时可重开
- 无效或旧版本记录按首次处理，不访问或删除原项目数据
- 存储异常时继续本次导览并说明进度未保存
- `?isolated=1` 不读写引导持久化；刷新可重新演示，不影响正常站点偏好
