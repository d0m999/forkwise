## 启动

从仓库根目录运行：

```sh
python3 -m http.server 48933 --bind 127.0.0.1 --directory prototype/open-canvas-r2-20261011
```

打开 `http://127.0.0.1:48933/`。无需安装依赖、构建或登录。服务只绑定本机，不是公网网站。

内容保存在当前浏览器与访问地址对应的 localStorage；换地址、端口、浏览器不会自动迁移。项目菜单可导出 Markdown 和完整项目 JSON。私有浏览、清理站点数据或浏览器存储故障会影响保存，请导出保留重要试用内容。

本人在 Q47 确认整体理解准确、可以收束。本轮将已确认的交互统一补入同一 R2 主原型，沿用认可的布局与参照 B 站缩小后的小窗。没有新增独立 HTML，没有改生产实现、正式设计访谈或 ADR；原型完成不代表真实四站能力或生产验收。

打开 [小窗观看](index.html?isolated=1&video-demo=1&video-view=mini)，或顶部「视频演示」。入口使用隔离会话，刷新重置示例，不读取或覆盖原浏览器项目。本地自制 SVG 动画无音轨。左上「画布内观看／小窗观看／移出视野」切换基本场景；「更多流程…」提供识别、封面失败、竖屏比例、起播时间、结束、重试及写字板场景。加载演示约 12 秒后返回，也可用「完成识别／补齐信息」立即推进，以便先移动或缩放再观察。

### 加入与补齐

- 普通粘贴：只有一个网址的分享文案提取网址，不另生成附带文案；多个网址则全文按既有普通文本粘贴处理。每次粘贴新建对象，各自位置、尺寸和连线独立。
- 精确主机与路径判断支持 YouTube 视频长短地址、哔哩哔哩 BV／AV、抖音视频长链。已知短链及小红书笔记候选先生成「正在识别链接」占位；主页或未知网址不自动认定视频。底部「添加视频链接」可以显式加入未知站点。
- 占位可移动，识别与信息补齐始终更新同一对象；无法确认时，普通粘贴原位转为普通链接（沿用 R2 的文字卡片承接），显式加入则保留视频对象。待识别占位双击只提示等待，确认后仍需再次双击。
- 标题、封面分别保留已经取得的部分；失败提供手动重试，仍可移动或尝试观看。尺寸首次取得时，未手调大小则保持中心并按横竖比例、可用空间调整；手调过则保留外框，画面等比容纳。
- 视频是独立画布对象，可普通连线、复制、删除和撤销；没有写字板、标签或卡片搜索身份，不转为来源或证据。

### 观看与返回

- 单击选择，双击封面或标题行原位观看；聚焦对象后 Enter 也可进入。拖标题行移动对象，四角等比缩放画面；移动、缩放、取消选择不结束播放。
- 同一时间只有一个播放器。双击另一个已确认视频结束当前观看；新视频按分享时间开始，无时间则从头。播放状态留在内存，不进入项目撤销历史。
- 画布内操作条为「小窗／全屏／关闭」，小窗为「回到画布／全屏／关闭」，位于画面外。画布、小窗、全屏共用播放内容；全屏返回按钮与 Esc 均回到进入前的模式。小窗模式 Esc 不关闭观看，交给当前画布编辑或菜单。
- 小窗首次在可见画布右下角、底部工具上方；标题行可拖动，也可聚焦后用方向键微调，没有手动尺寸入口。本次使用记住最后位置，关闭或更换视频后再开沿用；空间变小会夹回可见区域，刷新重置。
- 横屏小窗目标宽度约为可见画布的 21%，常规范围 280–420px；竖屏优先约 240–300px 高，再考虑播放器控件下限与可用空间。本地 16:9 小窗在 1386px 宽画布约 291×164px。YouTube 按官方要求至少 200×200px，16:9 时约 356×200px；空间不足则显示放大或全屏提示，不能以缩裁控件来满足外框尺寸。
- 小窗时原对象保留封面、站点名、标题及「小窗观看中」。双击原对象原位接回，保留视角；「回到画布」则将原对象中心移到可见画布中央，缩放、对象几何与连线保持。
- 完全移出视野后继续播放，主导航下方、可见画布顶部居中显示「定位视频／小窗／关闭」，不会自动开小窗。定位只平移视角；侧栏打开时按剩余画布居中。
- 写字板占满工作区时，已有小窗浮在写字板上；画布内观看转顶部控制条。点击定位或回到画布：宽窗还原原侧栏宽，窄于本原型 963px 断点时收起写字板，再居中视频，保留正文与缩放。
- 初次观看时过小，显示「放大视频，或全屏观看」及全屏按钮；已经开始后缩过小仍继续计时，放大可恢复画面。提示保留可读尺寸，不改原对象外框。
- 自然结束保留当前观看模式和结尾，提供重播。关闭、切项目或删除正在观看的对象结束观看；撤销删除只恢复封面，不自动播放。切其他应用不主动结束，页面小窗随见岔窗口退到后台。
- 播放临时失败保留当前模式，显示原因、重试、打开原页面和关闭；能恢复则说明从中断处继续，否则提前说明从分享起播时间（无则 0）重来。确定无法嵌入时提供原页面入口。打开原页面使用新标签，并结束见岔内观看。

### 已接入与演示边界

分享文案提取、纯 URL 分类、起播秒数解析和上述状态切换已经接入原型。真实短链展开、内容类型确认及完整元数据获取**尚未接入**：加载成功、失败、比例补齐和恢复进度通过明确标记的本地场景演示。真实候选无法确认时按回退规则处理，不把它谎报为已识别视频；异步请求通过对象身份守卫，删除后的结果不会复活对象。

真实 YouTube 链接会按 ID 请求远程缩略图；尚未获得真实标题。实际打开后，YouTube 与哔哩哔哩按各自[官方播放器参数](https://developers.google.com/youtube/player_parameters)和[官方外链播放器文档](https://player.bilibili.com/)创建嵌入，携带起播时间／分 P。抖音、小红书及未知站点目前提供原页面入口，不用普通网页冒充可嵌入播放器。不下载视频、不绕过限制、不调用外部模型。

Chrome 验证使用本地无音轨动画，不能证明四站真实播放、音频后台连续性、登录态、跨域结束／错误事件或精确进度恢复。真实播放器内部获得焦点后 Esc 可能无法传回页面，画面外返回按钮仍可用。外站失败提供手动「播放遇到问题？」入口；跨域内部失败不保证自动检测。封面本机资产保存、播放中的对象重叠遮挡、极端窗口与完整辅助技术仍未验收。来源继续暂缓。

模块为 `video.js`／`video.css`，接口接入 `canvas.js`、`clipboard.js` 与 `panels.js`。本轮语法、既有模型检查及实际浏览器记录见私有 `docs/plans/video-interaction-prototype-2026-10-24.md`。

## 既有设计方向

克制的纸面工作台：暖灰点阵画布、白色内容、杏色标题区域，紧凑顶部项目页签与底部创作工具。右侧写字板专注完整正文，搜索为独立居中窗口，避免把阅读预览变成画布操作。颜色与品牌来自基本品牌包；其余中性色仅服务信息层级。图标复用并调整 Lucide 基础 SVG 轮廓，ISC 与 Feather 派生 MIT 许可见 vendor/LICENSE-lucide.txt；中文系统无衬线字体，无外部字体请求。

Taste 的层级、留白、克制配色、状态与响应式检查适用于此密集工具；没有套用营销网站的装饰性版式、强动画或无关功能。

## 已落入原型的范围

- 项目切换、新建、重命名；独立浏览器保存；修改统一撤销/重做
- 卡片放置、标题、可重叠布局、移动和调整尺寸
- 右侧写字板：所见即所得正文、按需格式菜单、标题/列表/图片、块顺序、自动保存、展开/还原
- 自定义标签及当前项目卡片搜索，关键词与标签交集，只读预览与明确打开画布分离
- 五种形状、独立文字、图片、画笔与荧光笔、普通连线、组合与分区
- 图片裁剪预览/完成/取消、恢复原图、90°旋转和大图查看
- 普通连线可选择直线/折线/曲线；连线不建立领域推导，不触发AI
- AI 工具只提供明确标注的本地模拟候选，点击明确添加才产生新卡；没有真实模型或公开资料查证

## 不能当成生产验收的部分

这是可操作原型，不是生产引擎重选或全量 D01–D423 实现。中文搜索已本地打包 jieba WASM 与 OpenCC，支持简繁等价与原文命中映射；依赖及许可证位于 vendor。大型文档、复杂嵌套列表、外部剪贴板跨应用兼容、性能与所有辅助技术尚未全面验证。裁剪、层级、跨项目剪切等复杂边界需以本轮检查记录为准，不把代码存在等同验证完成。

暂不接后台、SQLite、真实AI、账户、发布服务或旧研究工具。
