## 打开

双击 [启动画布原型.command](启动画布原型.command)。它在 `http://127.0.0.1:47865` 启动静态页面，默认打开带操作引导的 Intel 示例 `forkwise-step-prototype.html`。再次启动会复用同目录的服务；关闭提供服务的终端即可停止服务。端口被其他服务占用时明确报错，不随机换端口。

也可以运行：

```sh
python3 prototype/serve-canvas-prototype.py
```

如需指定端口，可设置 `FORKWISE_PROTOTYPE_PORT`（1–65535）；浏览器存档按访问地址隔离，换端口、换浏览器或换浏览器配置不会自动带出旧存档。需要迁移时先导出工作区 JSON，再从新入口恢复。

默认只有一张融合画布：完整 Excalidraw 编辑器承载自由绘图，研究卡片、来源入口和推导关系直接放在同一场景中。旧 HTML 仍可直接打开；`file://` 模式使用原研究画布作为兼容回退，并提供本机服务的启动提示。

## 绘图工具与研究流程（D84，2026-10-06）

## 怎样研究

1. 页面直接进入画布，在中央粘贴观点或导入 TXT / Markdown。粘贴时可说明所保存的是全文、摘录或范围不确定，默认摘录；原始地址选填，只保存、不抓取。要体验完整流程，先点“使用模拟案例”，再点“梳理并查证”，生成模拟候选链。自己的文本会保留，但真实模型未接入，界面会说明无法自动分析，不会套用示例答案。
2. 单击选中研究卡，点就近“查证与立场”，在同窗查看依据、范围与缺口，并表达个人立场；两种状态分别保存。也可直接点击彩色立场标签。通过“来源”看原句、材料版本、时间与位置，并按实际保存范围进入内部阅读，可放大、还原和返回画布。有实际网址时另可主动“打开原始网页”，该网页是网站当前内容。
3. 直接研究需要的主张或整步推导：保存改写、立场、笔记或依据后成为个人研究项；仅阅读的来源内容与 AI 候选仍保持参考性质。未表达立场时仍为待研究，不因可编辑就默认认可。
4. 从主张正文区域拖 A 卡片到 B 卡片，新增 **B → A**。同一主张可有多个后续主张，重复与成环仍被拒绝。推导理由贴在线上；单击选中后用“查证与立场”查看依据并判断这一步，用“推导”查看结构，也可拖动理由调整摆放。
5. 选中卡片后点“改写”，直接修改正文，保存后回画布（D68）。共享前提须先明确涉及哪些推导，再选局部版本或显式全部。一次有内容变化的保存记一次修改；长主张增高及对应避让仍可研究撤销。用“更多 → 修改记录”回看前后内容；用“更多 → 删除”移除个人卡及相连推导，可撤销恢复。
6. 随时用原生工具手绘、加文字、图片、图形与批注。点“＋ 新建卡”直接写主张；选中自由文字后点“整理成主张卡”，在原文字旁新增个人主张，原绘图素材保留。
7. 选中一项或多项研究对象后点“AI”，在明确的本地模拟范围内先看回答；显式添加后出现 AI／待研究候选卡，不自动连线。样式和聚焦从就近工具进入；聚焦只调视口，返回后继续原位置研究。

Excalidraw 自由批注继续属于同一研究画布。本人的主张可在自动整理前先写，随后整理结果不得覆盖已有个人内容。step 入口自动保存研究与绘图，可主动导出工作区 JSON；只需图片或普通绘图时仍可导出画布文件。旧入口刷新会清空页面状态。
