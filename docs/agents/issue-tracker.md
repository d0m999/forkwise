# Issue tracker

- 类型：GitHub Issues
- 仓库：`d0m999/forkwise`
- 入口：https://github.com/d0m999/forkwise/issues
- PRs as a request surface: off

## 读写方式

使用已授权的 GitHub connector；具备已登录的 CLI 环境时，可使用 `gh issue`，并显式指定 `--repo d0m999/forkwise`。创建、修改、评论和关闭均遵守本次用户授权；配置本文件本身不授权发布事项。

裸编号 `#N` 属于本仓库。先核实它是 issue 还是 PR；日常分诊队列只纳入 issues，用户明确指定的 PR 可单独处理。规格与工单发布前先搜索现有事项，保留既有讨论和依赖，避免重复创建。

## 内容边界

仓库现有隐私规则继续适用。引用私有 PRD、计划或研究结论时，先核实当前任务授权与接收范围；不能因选用了 GitHub Issues 就把私有正文复制到远端。未确认的产品提案保留待决定状态。
