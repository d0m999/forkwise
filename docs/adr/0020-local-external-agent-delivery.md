# ADR 0020：本机外部 Agent 研究与受限委托

日期：2026-10-09。状态：本次用户交付计划授权的工程实现；产品边界见 D149，验收另记。

外部研究复用 jobs 和领域操作，不在 MCP 中另写数据库规则。任务固定材料、目标与推导直接上下文；执行器、创建者、重试来源保存在任务输入并随资产往返。外部任务不得由后台模型领取。提交经结构及引用校验，过时结果仅留历史；部分完成／失败保留缺口，重试另建记录，取消后提交拒绝。所有写入及回执在同一事务中提交。

本人签发的项目授权可附 personal_record 能力；默认无，旧授权无。仅立场、对象采用、笔记与条件人工记录允许委托，执行者仍是 Agent 并记录委托依据；不能冒充本人逐句审核。授权、整项目删除、恢复、转写人工核验等仍由本人操作。会话及能力不进入备份。

路径导入默认关闭，由数据目录 import-roots.json 按项目列绝对目录。只读取根目录内非符号链接的单个普通文件，验证打开前后文件身份、指纹和大小；同幂等键优先回查原回执。

基础图形共用已有 canvas.annotations，稳定 ID 操作只修改这份规范数据，研究位置仍用 positions。旧 drawings／Excalidraw 场景原样保留，不自动改写旧场景；正式引擎仍按 ADR 0011。图片引用项目内原文件，并通过既有画布本地图像投影显示。

材料分段返回固定版本、指纹、绝对 UTF-16 位置和解析锚点；外部转写绑定原文件指纹、页面及区域，独立保存且永远未人工核验。数值工具不证明 Agent 财务输入已验证；混合条件仅明确共同满足时合并。

交付按源码版本固定；真实 Codex、SEC、界面、恢复证据分别列出，禁止将协议夹具称为真实研究验收。
