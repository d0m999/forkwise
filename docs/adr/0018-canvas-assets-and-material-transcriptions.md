# 画布资产、材料转写与本机恢复边界

2026-10-08，依据 D118 授权实施 D120–D122。

原 Excalidraw 组件由后端领域对象生成投影。投影不存成另一份可任意编辑的图谱；图谱命令与布局可在一个 SQLite 事务中提交，各自检查版本。自由绘图仅承载展示资产，样式采用字段白名单，不能覆盖领域投影；Agent 不得修改人类编辑草稿。客户端将保存串行处理，自己的布局回执不重建正在编辑的窗口，跨入口更新仍执行显式版本冲突检查。

原文件采用 SQLite BLOB，便于单机一致备份，代价是数据库随材料增长。首版明确限制单文件与单次模型任务范围；解析 worker 限定内存和时间，后续若真实材料规模要求独立对象存储，再依据容量数据修订。解析正文、区域定位、OCR 初稿与人工校正作为独立版本产物；校正保留原文件和来源时间，不能写成作者修改过原文。

本机 Ollama 多模态调用是可配置适配器，使用带标签的模型和结构化输出。图像区域归一化到原图宽高，模型区域标为未核对；原图与文本对照后由本人确认和更正。成功识别表示任务覆盖，不证明文字、区域或整条论证正确。单页转写明确范围，未知费用为空。真实模型识别质量待 OD-24 的样本验收。

备份包含任务历史，因为立场理由草稿和评估可引用任务身份。校验指纹按版本演进，凭据不进入备份。恢复通过隔离副本校验、停服预览确认、切换前备份和持久日志处理故障；到期清除覆盖管理中的本机副本，失败不能报告已完成。

实现、未完成范围和验证证据见 [后端进度](../plans/backend-implementation-2026-10-08.md)。本 ADR 不宣称旧原型完整迁移、统一撤销、真实模型或首例研究验收完成。

2026-10-09，D131 增加 `forkwise-prototype-workspace` v1 的显式迁移。转换器复用 `ArchiveService` 的只读完整性校验和原子导入，预览与确认共用转换代码；每次只迁移一个项目，恢复文件不携带其他项目的数据。当前对象转换为新的版本化业务对象，原版/基线/旧历史等保存在私有 JSON 文件资产并提供只读回查。旧事件没有可靠的完整时间与操作者，强行转换成后端版本序列会制造虚假的审计和历史时点，因此新版本从导入时开始，旧记录保持原有含义。原文件、恢复文件及说明沿用 SQLite BLOB、资产导出和项目清理，不引入可覆盖日常图谱的整工作区写接口。

转换器行为改变时须更新转换器标识，使既有预览失效。未知或过时的引用不绑定到当前对象，原始数据仍保留供复核；图像区域和旧对象来历的结构化适配继续开放。此选择以可恢复且诚实的历史为先，代价是部分旧操作需要从只读记录重新研究，不能直接使用新后端撤销命令重放。大小限制、剩余映射和验证证据在 D131 与后端进度中明确登记。


2026-10-09，D132 为对象材料增加独立归属对象，并将引用扩展为文字定位或原图区域的联合契约。原图区域固定文件身份及自然尺寸，材料列表使用固定材料版本；归属不混入证据作用字段。Canvas 图片入口先读取已保存布局，写入在同一 SQLite 事务中完成来源、原文件、材料版本与归属，内部复用业务命令并合并完整变化集合。失败不留下文件孤儿，日常同步仍沿用有序业务收据。此阶段不引入全局内容地址共享服务。

旧文字引用结构保持兼容；新增图像引用的资产恢复必须核对文件、尺寸及区域，不能因没有 quote 字段就跳过校验。原图文字未识别时，文本模型不能宣称读取了视觉内容；外部 Agent 仍经同一引用校验及候选权限边界写入。新证据关联补齐固定的推导上下文，旧无上下文关联保留历史但不直接当作当前依据。具体限制与剩余旧档转换见 D132。

受限原图的同内容副本也可能存在于画布文件资产中。导出和隔离备份按已知受限文件指纹过滤这类画布字节副本，保留位置并标记文件不可用；不在原库删除图片。此规则仅识别同指纹原始字节，不声称识别裁剪、重编码等衍生图片的权利归属。

2026-10-09，D133 将旧转换器升级为 v2，迁移对象材料可见性及可验证的静态原图区域。只复用同一来源内相同指纹的文件资产，各来源版本与时间独立；不引入跨项目去重。旧图像区域必须匹配原文件自然尺寸，静态性不能确定的旧引用保留原档，避免把未记录的动画帧重解释为第一帧。推导证据的上下文从已验证的旧内容签名重建。v1 迁移说明可继续读取，v1 已导入项目没有自动升级或覆盖路径。此处修订前文的图像区域待适配范围；旧版本来历及撤销重放仍未完成。

2026-10-09，D135 将材料保存范围固定在来源版本上。解析成功只说明解析任务完成，不能据此推定保存了外部材料全文；缺省的旧记录按范围未知处理。文字阅读复用按项目授权的既有材料接口，以保存版本的指纹和原引用校验定位。失效引用需要明确后续处理，不在阅读入口自动重定位或换版本，以免改变证据含义。当前以有界 DOM 分段改善长文本阅读，完整文本传输和后续超大材料能力仍分别评估。


2026-10-09，D149／ADR 0020 修订本次本机交付：研究与定性分析可以由外部 Agent 执行，内部模型非验收前提。项目个人记录委托是本人签发的独立能力，保留 Agent 执行者，不等于冒充本人逐句核验；历史默认无此能力。外部转写只能另存未核验版本。混合评估只有明确 `mixedCombination: joint_required` 才自动合并，未指定时保留分项与 Agent 总体意见。此前实现及测试记录保持为历史证据，真实验收见对应交付报告。
