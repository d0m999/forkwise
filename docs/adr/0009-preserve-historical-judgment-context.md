# 历史判断默认使用当时的材料与评估记录

后来取得的材料、原文修订与新评估会改变当前研究依据，直接用于展示旧判断会混淆当时记录与事后信息。决定回看已保存判断时默认使用其当时的材料版本与评估记录，后续信息另行对照，使用当前信息重新审视旧判断也不改写历史记录。相较只保留最新材料与评估，这需要保留历史版本及其对应关系，但能解释研究者当次判断所依据的信息。

访谈 D36 确定记录入口：日常编辑自动保存并保留编辑历史，完整历史判断记录由研究者主动创建。记录保存当次论证、个人立场、作者对照基线、材料及识别文本版本和评估依据；后续编辑或转写校正不替换当次引用。保留修改历史与主动记录的一次判断分别用于追踪研究过程和回看当次研究结果。
