# 自由放卡、标题输入和原子几何编辑

状态：工程采纳；Issue #8 当前普通卡片切片。固定起点 efbb437；运行结果以本票私有施工记录及最终候选检查为准，不代表完整首版或本人验收。

## 范围与引擎

依据 D151、D251–263、D288–312，按 D301/D302 后决定优先。继续使用 React Flow 12.12.0 与现有 Mapping、Node/SQLite，不恢复 D298–300 的禁重叠、附近避让或邻卡限制，不新增自动排版、关系、完整搜索、混合对象层级或完整写字板。既有正文、草稿、冲突和删除态入口继续保留。

卡片工具的指针或键盘激活只进入放置状态，点击画布落点才创建，包括已有卡片上的落点；不会先在中央建卡或打开正文。落点沿既有左上角世界坐标，默认 280×160。创建与连续首次标题沿既有 editGroup 合并；已有标题的一轮单独合并，无变化不入历史，其他成功操作截断合并。空 title 是空字符串，未命名仅为显示占位。

标题菜单与双击进入同一编辑轮次；Enter 完成、Shift+Enter 换行、Esc/外部点击保留，composition 优先。轮内保留 textarea 原生输入 undo/redo，项目历史路由不同时触发。轮次固定原生 defaultValue，仅当草稿/权威回读值与实际输入不同才更新 DOM value，避免每次改写 defaultValue 产生看不见的原生撤销步骤；输入、generation、原请求和 expected 仍由原草稿协调器负责。正文双击沿已有单文本块正文入口，不冒称后续完整写字板。

## Mapping 合同

新增 `pose.batch`，经既有 `/api/mapping/execute`：

```json
{
  "commandId": "gesture-id",
  "projectId": "project-id",
  "type": "pose.batch",
  "expected": { "card-a": "pose-version-a", "card-b": "pose-version-b" },
  "payload": {
    "poses": [
      { "id": "card-a", "x": 100, "y": 120, "width": 350, "height": 200 },
      { "id": "card-b", "x": 500, "y": 120, "width": 280, "height": 160 }
    ]
  }
}
```

- 非空列表、每卡一次；expected 必须恰好覆盖目标卡片 Pose 版本。位置有限数，宽高有限正数；UI 尺寸手柄采用 120×80 的交互下限，此数值是工程选项，不是最终外观验收。沿现有 HTTP 1,000,000 字节请求上限，不新增选卡数量限制。
- 在同一 SQLite 事务内读取当前卡片、校验全部身份/版本后才写任何目标。只生成实际改变的 Pose 版本，保留当前 Thought/Body、块身份及创建序位；不接受旧几何草稿夹带的正文。冲突、删除、跨项目、重复目标、失败检查点全部回滚。授权先于幂等；失败不占 commandId，成功原请求跨重启返回原 receipt。
- 一次批量动作一个 revision、一个历史步骤。Change 增加可选 `cardChanges`（完整 before/after 卡片列表）；before/after 的首卡兼容既有形状，changedIds 和 observe 的 pose domains 覆盖全部实际变化目标。保留各卡不可变版本。undo/redo 只恢复该动作的 Pose，生成新版本，不覆盖后来的正文或标题。
- 单卡普通移动保留 `pose.move` 兼容路径；多卡移动与尺寸调整使用 batch。完成前只预览，取消、失去捕获、窗口中断或 Esc 恢复；未知已提交结果仍用原请求重试，取消预览不丢弃待确认命令。无变化的手势不派发空写入；服务端 no-op 合同也保留。

尺寸手柄可聚焦，方向键以 10 个世界坐标单位调整对应边；非该手柄的方向不产生变化或历史。原有位置方向键入口保留，并在纯卡多选时整体移动。

## 选择、吸附与临时显示

选择工具下完整包含框选，普通框选替换/空命中清空，Shift 追加不反转。选区由 UI 身份集合表达，拖动任何已选卡整体平移，保相对位置。取消选择和多选保留当前正文绑定；卡内明确正文入口继续只编辑其对应卡。框选外框不拦截卡内操作。取消时通过引擎公开 store Interface 清掉其残留的临时框选字段，不写 Mapping。

拖动以单卡或整个多选外框的边/中心吸附至未移动卡片的边/中心，显示辅助线。采用 R2 的 6 屏幕像素阈值；默认开、可见点击关闭，Alt 拖动暂禁并在松开时恢复原开关。已核对当前 Shift 多选、Space 平移及 Meta/Control 历史键位。Alt 和当前 UI 会话开关范围是工程选择，不冒称 D295 已逐字固定键位或长期偏好。选择/移动工具、Space 临时平移及缩放均不生成研究历史。

当前只有普通卡片。渲染沿 ADR0022 明确读取的 `creation_ordinal`，新卡在上方；纯卡选择借引擎临时 elevation 置前并保内部次序，取消恢复创建序位，保留几何修改。它不是新持久 StackOrder，不能从 DOM/id 排序补造该域。后续搜索明确打开复用同一 UI 选区与临时置前路径；四类共同持久顺序及混合对象由所属票扩展。

## 验证与限制

主要 seam 是 Mapping.read/execute/observe + 真实临时 SQLite，补真实 HTTP、MCP SDK、本机 Chromium 的指针/键盘/重开及 UI/Agent 同 snapshot。检查点故障注入只在存储提交 seam；取消事件注入标为浏览器故障测试。真实 OS IME、设备中断、系统 clipboard、第二 OS、本人 UX、后续富文和生产数据未由这些自动检查证明。最终 SHA 全七组与独立 Standards/Spec 的实际状态仅见本票记录；无旧票 PASS 借用，无数据库迁移或资产清理。
