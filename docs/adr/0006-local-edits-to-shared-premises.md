# 共享陈述明确修改范围，局部改写派生新对象

研究者既可能修正所有引用共同使用的内容，也可能只在部分推导中尝试不同假设。D109（2026-10-08）确认：共享陈述保存前先展示引用它的推导，由编辑者明确选择全部更新或仅修改选定推导所用内容；未选引用保留原内容。此决定沿用 D66 的明确范围规则，修订 D25 在本 ADR 中“默认当前分支”的旧表述。相较自动决定修改范围，这增加一次范围表达，但能保留研究者选择的其他情景，避免系统猜测编辑意图。

D110（2026-10-08）在 A/B 前端草图对照后选择 A：仅修改部分引用时，派生具有新身份的陈述，选定推导改接新对象，未选引用保留原对象及内容。新陈述记录改写所依据的原对象及当时版本，新旧陈述可分别继续编辑，原对象后续修改不自动同步至派生对象。“改写来历”用于溯源，不构成推导或支持关系。

相较同一对象同时供不同推导引用不同版本，此方案增加独立对象，但让不同假设各有明确身份；各对象仍保留自己的编辑历史。旧 `branch_local`／`BranchNodeOverride` 的同身份覆盖方案由本决定替代，具体字段、来源绑定与旧数据迁移待重新设计；D110 不确定全部更新的版本细节。

D111（2026-10-08）选择保留原有证据作为新陈述的参考，确认其对新陈述的作用后另建关联。原材料版本与引用可回查，旧支持／反驳关系及解释仍属于原对象；参考展示不建立对新对象的生效证据关联，不继承旧查证结果或立场。新关联针对新陈述的内容版本，原材料和原关联保持；参考状态与确认操作的具体存储和界面仍待设计。

D112（2026-10-08）选择保留原有上游推导，派生时不自动复制或迁移到新陈述。研究者按需为新陈述另建独立推导，可以复用原有前提与理由；新旧推导分别维护，不因复用内容共用推导身份。已选下游仍按 D110 改接，未选引用保持。此方案要求明确补充新假设的理由，同时保留原有论证及改写来历；具体复用入口与契约继续设计。

既有 D32 关于实质改写后立场待研究、原立场留在历史与继承记录的规则保持。前端可展示原陈述与派生陈述并提供改写来历入口，草图布局不作为固定控件规格。正式前后端尚未按 D110 实现。

D46 补充：先用临时假设预览检查前提不成立时哪些推导支持受到影响、哪些独立支持仍保留；预览保留原内容和判断，组合关系未明时显示不确定，不把影响解释写成结论已被证伪。本人明确保存后才按上述范围与身份规则形成个人条件路径或派生陈述；预览与保存后的内容修订分别处理。
