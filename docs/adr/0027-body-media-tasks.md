# ADR 0027：正文不可变媒体与绑定目标的异步任务

状态：已采用；日期：2026-10-16

依据 #16、D281/D282/D283/D285、ADR0015/0019/0022/0023/0026。保留现有 Mapping read/execute/observe 与独立 workspace SQLite，不触及旧研究库，不增加编辑器、消息队列、远端服务或第三方依赖。

资产是真实原始字节及安全解码后的元数据，按项目/ID 不可变保存。选择沿用当前512 KiB 暂存保护与1 MB HTTP上限；更大媒体通道另行验证，不能借本票放宽已有保护。像素解码在独立限时 Node worker 中完成；同步 Mapping 资源命令最多等待5秒，其间服务请求会排队。UI 上传不阻塞编辑线程；不把这一方案描述为后台服务队列或吞吐量验收。静态 SVG 先有限子集校验，原字节不改写；媒体下载继续项目授权与独立 CSP 沙箱。

媒体命令以原项目/卡/块/ticket的SHA-256推导稳定身份，跨重开继续原请求；上传ACK缺失可通过完整不可变资产读回确认，未知结果保持待确认。任务票据不可变绑定原项目/卡/块及原始请求，生命周期单独持久保存，不因历史恢复重新激活。占位与失败可保留字节；删除、取消、撤销或替换使旧票据退休。完成只在原处更新块，替换保旧显示参数、图注与alt。失败不覆盖旧图片；新重试分配新票据，仍属于原用户动作。

资源创建不占40步。异步完成/失败/重试精确补全持有原票据的历史快照，给变更后的 Body 分配并保留不可变版本；不新增一步，不跨越中途其他卡片的操作。Body、变更、回执、票据及历史保持同一事务；媒体成功不能只由元数据或占位保存推定。

#17 另行负责正文图调宽与期望宽、图注alt编辑、大图及动图控制。本票只读呈现和保全兼容字段。工程接口见 [BODY-MEDIA](../architecture/mapping-contract-v0.1/docs/BODY-MEDIA.md)，真实检查与未测边界见本票私有实施记录；本文不代替正式双轴审查或验收。
