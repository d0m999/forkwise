# 显式保留前提的共同依赖与独立支持

多个前提指向同一结论时，仅凭单条箭头无法分辨它们是某一步推导共同需要的前提，还是各自提供支持的不同理由。决定显式保留共同依赖与独立支持的区别，共同依赖时以整步联合推导记录个人立场，原文未说明时保留不确定性，AI 补充仍标为推断并供审阅。相较只用箭头与备注，这会增加论证重建、编辑和关系记录的复杂度，但能解释某个前提变化究竟影响哪组推导及哪些支持仍然保留。

第一性原理访谈 D105／D106 明确：每条可独立讨论的理由对应独立推导，必须共同配合的多个前提参与同一步推导。D113（2026-10-08）进一步选择每项推导恰好对应一个结论；相同前提导出不同结论时分别建立推导，各自维护理由和立场，前提可继续共享。相较把多个结论放进同一推导，这会增加推导对象，但能让每一步的说明与判断对应明确的结论，分别修改和质疑。

对象独立性通过连接和推导标签呈现，不要求新增独立卡片。自动拆分、批量创建和迁移协议继续设计，本轮仅记录语义边界，未修改正式实现。
