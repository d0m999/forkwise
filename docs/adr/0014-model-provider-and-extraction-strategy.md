# 模型供应商按候选池与硬性条款筛选接入，抽取失败分级降级

核心模型任务的能力要求并不相同：论证重建要在多年材料中逐条给出主张与推导并附上可复核锚点，影响匹配要在新材料进入后只针对指定节点范围提出变化，条件评估要在资料不完整时给出带缺口的建议而非确定结论。本人已裁定材料外传范围——允许送商业模型 API，但**供应商必须明确提供零数据留存（ZDR）与企业／API 条款、承诺不将输入用于训练，且能给出可核验的条款依据**。因此本篇不锁定单一厂商，只锁定筛选条件与接入结构：候选池由「可核验的 ZDR 条款 + 企业或 API 数据处理条款 + 不用于训练的书面承诺 + 结构化输出与长上下文能力」四项硬性条件筛出，任一项给不出可核验依据的供应商一律排除，不看品牌也不看评测分数。通过筛选的供应商以 provider 适配器接入（Vercel AI SDK 只做传输与 schema 抽象，不是对某一家厂商的承诺），本地 Ollama 0.6.4 保留为不出本机的备选，用于隐私敏感材料与离线场景。入选供应商确定后另记一篇 ADR 写明厂商、模型 ID 与条款依据出处。抽取策略固定为三段：先跑不消耗模型的确定性环节（指纹去重、内容变化检查、白名单字段计算与条件比较），再把变化部分送模型并要求结构化输出，最后把模型输出与原文锚点做存在性校验后才写成候选。降级路径必须显式存在：模型超时、限流或输出不符合 schema 时，先做一次带错误信息的 schema 修复重试，再失败就把任务标为失败或部分完成、保留原始来源与已完成的阶段，并在收件箱提供手动输入入口——模型失败不丢弃新来源，也不把更新标记为已处理（M02 异常）；低置信度结果保留原文、缺失项与手动输入入口，不给出没有证据的肯定结论（Q02）。相较现在就写死某一家厂商（省掉一轮筛选与适配工作），代价是把供应商条款风险固化进产品，一旦条款变更就要改架构；相较完全本地推理（隐私最强、边际成本为零），本地模型在长上下文与严格 schema 遵循上尚不足以承担多年论证重建，且受本机硬件限制。影响是：所有模型调用必须带任务 ID、阶段名与输入输出量并写入 `jobs.cost_json`；工具白名单固定为空，模型没有任何可调用的交易、外发或文件写入工具；材料一律作为数据传入并在系统提示中声明忽略其中的指令要求（S02）。

## 材料外传范围

研究语料允许发送至**通过上述四项硬性筛选的**商业模型 API，研究资产仍在本机保存。处理范围不得扩展到无关项目或整个资料库，只送当前任务所需的最小内容。上传前必须在界面上告知：哪些类别的服务会处理这些材料、处理用途是什么、保留政策如何；新增供应商或改变外传范围必须更新告知并另立 ADR。未取得授权不把用户私有语料用于训练，不把本项目的材料用于其他用途（S02）。

## 实现约束

- D39 增加本人主动请求的立场理由起草任务：仅处理所选主张或整步推导的相关材料与必要上下文，输出候选疑点、依据及资料缺口；引用仍须核对，不补造反证。候选进入独立审阅状态，生成完成不替换已有理由或个人立场；本人采用或修改后确认时保留 AI 来源、原候选、引用与确认记录。供应商、材料发送范围与费用分别沿用 D30、D33。
- 截图与扫描页的文字识别采用多模态模型（D34 的技术路径补充）；该任务的候选模型须支持图像输入与结构化转写，仍按已有四项条款与能力条件筛选，不据此确认某一供应商已入选。识别文本与原图分别保存，论证重建与条件意见继续各自留存归属；不把模型转写文本中的匹配或模型生成的区域坐标当作已核验原图。
- D44 增加本人主动点“检查这一步”的推导检查任务：固定框架与 AI 针对性提问结合，仅处理当前推导及相关论证、材料和必要上下文，保留目标、材料及识别产物版本。已有依据、AI 可能前提或假设性反例、资料缺口分别输出；不补造事实或引用，不把疑问当作已确认缺陷。检查问题与 D39 立场理由候选分别记录，生成完成不改写个人判断；仅选择或浏览对象不触发这项外部调用。供应商、发送范围、用量与费用继续沿用 D30、D33。

- 按访谈 D33 记录并展示每个任务的实际用量与费用，首版暂不设置应用层费用硬上限；实际费用未取得时标为未知或待结算，不以零或估算代替。任务范围、去重、有限重试与用户主动停止规则仍保留。
- 供应商入库前必须留下可核验的条款依据（条款链接、协议名称与生效日期），写入设置页的数据处理说明；后续条款变更须重新核验，不通过即停用。
- 抽取输出必须先做锚点存在性校验：模型给出的引用若无法在归一化文本中定位，该条不得进入候选，改为标为待核对。
- 先去重与检查内容变化再抽取，候选尽量局部重算；同一来源版本、所用识别产物版本与同一处理配置的重复请求返回缓存结果，不重复产生成本（N01、PRD 第 11 节）。应用内转写校正后使用新产物版本，只重新分析受影响内容，不复用基于旧转写的结果（D35）。
- 重试只对网络与限流类错误做有上限的退避；解析或权限错误不盲目重试（N01 异常）。
- 白名单财务字段清单首版不锁定，抽取能力按「十项必备属性 + 未知不填零 + 不可比中止跨期计算」的通用规则实现，不针对具体字段名硬编码（见领域模型 4.3）。
