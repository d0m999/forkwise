# 主张与推导关系分别记录研究者立场

研究者可能认可某项主张，却质疑由该主张导向另一结论的推导，因此单个节点状态或整条链状态不足以表达其判断。决定在主张和推导关系上分别保留研究者显式标注的“待研究、认可、质疑、不认可”立场，共同依赖多个前提时以整步联合推导为标注单位，从作者论证收录且尚未表达立场的内容默认待研究。相较只标节点并把推导异议放在备注中，或仅为整条链赋状态，此选择增加编辑与版本记录的粒度，以准确保留分歧发生的位置。

访谈 D38 补充：主张或整步推导标为质疑、不认可时必须附一句具体疑问或理由，认可时理由可选。理由与对应版本和立场一同保存，前提理由不自动替代整步推导理由；历史判断和摘要使用当次引用版本的理由。该理由用于解释研究者的分歧，与条件评估依据和复核处理理由分别记录。

访谈 D39 补充：研究者主动请求时，AI 可依据已有材料起草候选疑点和依据，研究者选择、修改或确认后采用。AI 原候选、引用与研究者确认或修改分别保存；AI 不自动替换理由或选择立场，采用不消除 AI 起草归属。
