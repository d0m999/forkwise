# 首版只交付手动更新，架构预留定时接入

PRD 第 02 节将手动与定时检查同列为 P0，D16 又改为首版手动、定时获取与自动监控放到后续阶段，两处范围未收敛，导致监控的任务调度与额度边界无法确定。决定首版只交付手动导入新材料、定位受影响论证并提供影响建议，定时获取不在首版交付范围；监控实体与任务结构按定时可接入设计，后续增加调度不改动领域模型与任务层。相较直接实现一种定时频率，此选择省去首版的任务调度、额度消耗与失败退避实现；相较完全不考虑定时，此选择避免后续接入时重构监控与任务状态。PRD 第 02、08 和 13 节的相应表述随 v0.2 调整。

访谈 D48 补充默认研究流程：用户发起一次研究后，系统自动梳理观点，并在本次任务内获取允许访问的公开资料用于查证，再由用户审阅编辑。原文“手动导入新材料”针对持续更新，不禁止首次任务内的自动公开查证；后续新材料仍由用户主动导入或刷新触发，定时获取与自动监控不纳入首版。查证结果先进入材料与候选结果层，不自动改写个人结构、立场或人工条件结论；具体来源适配范围另按案例验证。
