# ADR 0021：项目许可采用 Apache-2.0

日期：2026-10-10。状态：用户确认决策。范围是见岔（Forkwise）仓库自身的发布许可选择。

用户为公开仓库选择开源许可，在宽松型许可中选定 Apache License 2.0。仓库已生成根目录 `LICENSE`（Apache-2.0 官方原文，版权行 `Copyright 2026 mempAw`），并配套 `NOTICE`、`CONTRIBUTING.md`、`CODE_OF_CONDUCT.md`、`SECURITY.md` 与根 `README.md`。`LICENSE` 已提交并随分支推送到远程仓库；仓库可见性按用户另行指示设置。

选择理由：Apache-2.0 是宽松许可，不阻碍未来任何商业化或闭源分发，契合「商业模式保持开放、未决定」的项目纪律；相较 MIT 额外提供显式专利授权与专利防御条款，对一个研究／AI 推理工具更稳妥；与项目现有大量 Apache-2.0 及 MIT 依赖在许可上无冲突。

许可边界：本许可覆盖本仓库自身代码，不覆盖第三方组件。字体、第三方依赖、模型权重、商标等按各自条款处理；发布产物的完整递归依赖许可清单以各构建产物内的 LICENSE 为准，未宣称已完成全部清理。已核项目生产代码不含 GPL／AGPL 污染；曾调研的 tldraw SDK（源码可见、非 OSI 开源）按 D52 已放弃采用、未进生产，不约束本项目自身许可。

注意：已分发的版本无法收回其许可；后续若要变更许可，只能适用于新版本，不追溯。许可解读不构成法律意见，正式对外发布前建议由律师复核。
