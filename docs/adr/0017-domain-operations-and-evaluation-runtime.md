# 版本化对象、原子操作批次与独立评估任务

2026-10-08，按 D118 auto-select 授权实施 D119。SQLite 保存类型化对象身份和不可变版本，关系表约束项目内引用；材料正文独立于图谱快照，避免每次编辑复制完整材料。对象写入版本用于冲突，内容版本用于证据和评估绑定，项目修订号用于变化同步；接口只允许明确的业务命令，不提供任意字段 patch 或整图覆盖写入。

`GraphWriteService` 在一个数据库事务中校验整批命令、相关版本、身份、引用与无环约束，再写入完整变化集合和幂等结果。请求中的幂等键绑定主体、项目与规范化请求摘要；相同键不同请求返回冲突。不同理由具有独立推导身份，不按端点组合去重。共享编辑必须显式指定范围；局部派生固定来历版本，旧证据只供参考，上游推导不复制。

数值评估与 Agent 任务在图谱事务以外运行。任务先持久化再执行，结果带规则/材料版本并追加为评估记录；人工确认是独立命令，Agent 凭据不能冒充本人。支持的本地确定性阈值修改自动重算，定性或混合评估须显式请求。取消、进程中断、超时、旧版本结果均保留可解释状态，重试不覆盖已保存规则或旧评估。

API 与本机 stdio MCP 调用同一业务服务。MCP 使用本机发放、按项目限制的 Agent 凭据；浏览器使用独立的人类会话。会话与原文/导出/索引保护覆盖所有入口。生产服务只绑定回环，Origin/Host 检查防止任意网站调用本机权限；模型调用不能获得人类确认能力。

检索先采用 SQLite FTS5 trigram，短中文词补充受项目过滤的子串查询。向量作为可重建索引保存在同库，按模型、维数和材料版本区分；无 embedding 配置时清楚返回全文检索方式。适配器安装或目录登记不表示资料已取得。

此次取舍减少独立常驻组件和跨入口规则重复；代价是必须维护对象类型校验与关系投影的一致性，并用事务、并发、历史回看和真实协议测试验证。实现进度与真实服务接入分别见 `docs/plans/backend-implementation-2026-10-08.md`。


D129 将验证节点实现为独立的版本化对象：AI 候选保留自己的身份，本人安排每个目标至多一份当前对象，修改追加该对象历史并保留候选版本来历。这样可以单独修改观察安排，同时不改变主张的内容版本、个人立场或已有查证目标。节点固定目标和推导的直接前提/结论内容版本；写入时仍校验相关对象写入版本。代价是读取当前安排时必须检查内容上下文是否仍匹配，不能把历史的 `confirmed` 字段解释为当前有效或预测成立。
D130 将共享条件的规则修改、引用调整、局部派生与人工评估接入同一业务服务。混合评估按“数值与定性共同满足”执行，并保存两个有依据的分项；确定性数值由服务计算，模型只评估定性要求，组合过程不赋予人工确认身份。这使数值不变量可直接测试、模型意见可单独追溯；代价是当前混合规则不支持任意自然语言布尔组合，不能把提示词中的“或”直接执行。条件任务摘要仅投影目标条件和规则版本，不携带完整输入材料，用于就近展示失败与重试。
