# 未决项登记册（Open Decisions Register）

本文登记见岔（Forkwise）项目中尚未明确、需延后处理的事项。

**读取入口（2026-10-12）：**当前范围和验收见[产品基线](../prd/current-product-baseline.md)，历史条目里的 PRD 章节指[归档旧稿](../prd/投资推理图谱_PRD_v0.2-2026-10-12-archive.md)。逐项处理前按设计访谈 D301 核对后续明确决定，旧开放项不自动恢复 D423 排除的专用工具；本次只同步入口，保留原条目与状态历史。

**使用规则**

- 只追加、不删除。新条目追加到文件末尾，编号递增。
- 三类固定 slug：`waiting-on-external-condition`（受阻于本次交付之外的条件）、`design-decision-to-evaluate`（有歧义、待重新评估的设计选择）、`existing-design-boundary`（有保留地接受的既有边界）。
- 一条被解决时就地关闭：把标题的 `OPEN` 改为 `RESOLVED`，`Status` 改为 `RESOLVED`，并补 `Resolution:` 行（决定了什么 + 为什么 + 日期）。不删除原条目。
- 字段缺失时写 `none yet`，不留空。
- 每次开工前，把仍为 `OPEN` 的条目复现到工作上下文，逐条判断能否关闭。

## OPEN — waiting-on-external-condition — OD-01 目标时间范围的具体起止与控件默认值

- **Date**：2026-10-01
- **Source**：访谈 D13；PRD v0.2 第 02 节、第 03 节、第 05 节 G01
- **Open item**：研究者自选的目标时间范围，其具体起止日期与选择控件形态（日期选择器／时期预设／手填）与默认值均未确定。首个案例尚未指定日期。
- **Related constraints**：目标时间范围必须与实际取得材料的覆盖范围分开存储与展示，缺口需可见；回看历史判断时默认使用当时已获得的材料（D28）；时间覆盖只描述已导入语料（I03）；未指定时不得默认套用「近一年」或「近三年」。
- **Current leaning**：不预设起止日期；本人自选目标时间范围，可参考实际材料覆盖，目标范围与实际覆盖分别记录，缺口可见（D13）。
- **Blocked by**：材料到位（首个案例的材料集合与导入批次，见 OD-09）。
- **Resolves when**：首个案例导入第一批材料、能看到实际覆盖区间后，由本人按实际覆盖确认目标时间范围并确定控件形态。
- **Status**：OPEN
- **Update 2026-10-01**：本人拍板「跟材料走」，本条保持 OPEN。slug 由 `design-decision-to-evaluate` 改为 `waiting-on-external-condition`；`Blocked by` 由「首个案例的导入批次与材料时间覆盖未定（OD-09）」改为「材料到位」；`Current leaning` 改为不预设起止、随材料覆盖范围确定。PRD 第 03 节示例与第 05 节 G01 已同步为「待定」，不再出现示例日期区间。
- **Update 2026-10-01（一致性清理）**：按 D13 明确由本人选定目标范围；实际材料覆盖是参考和缺口说明，不自动替本人决定或覆盖目标范围。具体日期与控件仍待材料到位后确定。

## RESOLVED — design-decision-to-evaluate — OD-03 账户结构

- **Date**：2026-10-01
- **Source**：访谈 D01；PRD 09 Project（「项目是权限与额度边界」）
- **Open item**：是否需要账户与登录、单用户还是多用户、认证方式，以及项目与账户的归属关系均未确定。

- **Resolves when**：部署方式确定后，按是否需要多人访问决定账户模型；若长期自用，可直接关闭为「单用户、无协作」。
- **Status**：RESOLVED
- **Resolution**：用户在 Q31 中选择首版本机单人直接打开使用，不另设应用账号或密码，保留本地访问保护（2026-10-01）。免登录不取消本地服务对原文件、索引及导出下载的访问校验；未来多人或远程访问需另行评审。

- **Update 2026-10-01**：ADR 0015 已确定备份与保留机制（本机两条备份、恢复窗口默认 30 天、`retention_days` 默认 30、删除覆盖备份副本），PRD S01 已同步写入。本条不因机制已定而关闭，关闭条件是实测通过。
