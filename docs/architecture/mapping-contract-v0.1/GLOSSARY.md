# 映射契约领域词汇

仅定义本提案上下文，不替代仓库的 [CONTEXT.md](../../../CONTEXT.md)。Thought、普通 Connector 与旧主张、推导关系不能直接等同；MaterialCard 等提案状态见 [CONTRACT 第6节](CONTRACT.md#6-决策状态不得合并)。

2026-10-12 新补字段的具体持久化表达见[字段映射](docs/STORAGE-MAPPING.md)；新增词条不代表隔离参考模型已经支持这些能力。

- 项目（Project）：一张思维地图及其资料、布局和历史的归属范围
- 思维节点（Thought）：本契约对应普通卡片的内容身份，不预设主张、假设或结论角色
- 卡片标题（title）：独立于正文的纯文字名称；空值的“未命名卡片”是显示占位
- 正文（Body）：思维节点中可编辑的内容
- 内容块（Block）：正文中可以独立辨识、排序和引用的一段内容
- 标签（Tag）：项目内有稳定身份、用户名称和颜色的分类；不自动代表研究立场
- 卡片标签关联（CardTags）：一张卡片引用的完整有序标签集合；顺序只属于该卡片
- 画布项（CanvasItem）：可定位的卡片、形状、独立文字、独立图片、笔迹或容器的视觉身份；资料卡仍为提案
- 形状（Shape）：基础几何外形及短文字，不拥有完整写字板
- 独立文字（Text）：直接放在画布的多行文字；一个对象统一字号，可有局部强调
- 独立图片（Image）：画布中的图片使用实例；原图资源与实例的裁剪、布局分别保存
- 笔迹（Stroke）：普通画笔或荧光笔的一段绘制结果，不是连线或正文
- 批注附着（Attachment）：已有随动批注的目标身份与相对偏移；与容器归属、普通连线绑定及资料附件分别表达，字段方案待实现
- 姿态（Pose）：画布项的位置、大小与允许的旋转，不包含前后叠放顺序
- 持久叠放顺序（StackOrder）：卡片、形状、独立文字与图片共同使用、由后到前的保存顺序
- 临时置前：选择期间的显示处理；不修改持久顺序，不形成历史步骤
- 资料（Material）：可被多次使用的一份资料
- 资料快照（MaterialVersion）：资料在某个时刻固定下来的内容
- 资料卡（MaterialCard）：地图上展示某份资料快照的一个实例
- 资源（Asset）：正文、独立图片或资料使用的不可变图片或附件内容，不等于画布图片实例
- 引用（Reference）：正文中对另一个思维节点或资料快照的指向
- 连线（Connector）：用户在画布上连接两端的表达，其含义由用户赋予
- 组（Group）：一层画布项集合，用于共同操作
- 框（Frame）：可以嵌套的空间容器
- 自由端点（Free endpoint）：不绑定画布项、固定于世界位置的连线端点
- 墓碑（Tombstone）：保留身份而不再作为当前内容存在的对象
- 版本（Version）：内容或姿态的一次不可变状态
- 行动（Action）：用户能够作为一个整体撤销的已完成修改
- 草稿（Draft）：尚未被权威状态确认的编辑内容
