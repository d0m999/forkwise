## 状态与职责

这是文档发布，不是生产集成或迁移。推荐生产沿用 TypeScript/Node.js + SQLite；Python 是隔离参考模型，当前不采用 CRDT，后续试验另行确认。未测生产性能或模型 token 消耗。

本目录的 ADR 编号只在本契约内有效，不覆盖[仓库现有 ADR](../../adr/)。工程参考选择、已有产品决定与待确认产品提案分别保留；一正文一摆放仍按契约的保守提案解释。

2026-10-28 后续决定 D425：首版采用普通卡片加附件，不新增 MaterialCard；附件复制固定同一版不可变原文件、各卡笔记独立，新版移除旧附件再添加新文件，无资料版本管理入口。附件在浏览器新标签打开，不支持则下载；普通文件拖空白建普通卡，批量每文件一卡，图片沿既定规则。独立MaterialCard及资料快照/版本管理UX不纳入首版；Material/MaterialVersion保留原参考状态，普通附件不因这些字段存在被要求实现该UX，底层复用沿既有代码/契约。GLOSSARY、局部ADR、既有参考模型和旧历史保留原文，不迁移删除旧能力，也不能据字段恢复已覆盖的UX；D425已确认行为仍待生产实现与验收。

仓库术语来源仍为 [CONTEXT.md](../../../CONTEXT.md)，已确认产品取舍与详细交互查[设计访谈](../../design-interview.md)，当前范围和验收索引查私有的[产品基线](../../prd/current-product-baseline.md)。旧PRD已归档；本契约不把技术验证视为新产品授权。

参考代码、测试、SQL DDL、原始日志、旧仓库证据副本及私有研究材料均不在本次文档提交中。涉及“已实现”的描述仅针对隔离参考模型；完整范围与生产缺口见契约第7–8节。

## 评审修订（2026-10-12）

- 标题独立于正文；项目标签有稳定身份，卡片保存有序关联，搜索读取完整内容，标签删除/撤销保留失效引用规则。
- Shape、Text、Image、Stroke 保留独立内容类型与对象身份；正文图片和画布图片不混用，保留统一字号、非破坏裁剪和禁止替换图片等限制。
- 四类内容对象共用持久 StackOrder；创建、复制、删除、批量跨层及撤销按同一事务维护，选择期间临时置前仅为 UI 状态。
- 随动批注明确附着、复制自由副本、删目标保留批注并解绑及撤销恢复，补 Attachment 与派生姿态的待实现映射；D261 的删卡面板状态列为待验，不套普通连线级联删除。
- 附着图片裁剪/恢复同事务保存必要 offset 与crop/几何，保留当前显示变换；offset未变只校验依赖，冲突无半写、undo/redo同一步恢复。P2的量化及并发场景见[验证说明](VALIDATION.md#附着图片裁剪与恢复待验场景)，仍待实现/验证。
- CRDT 候选资料已归并到统一[开源研究总览 §8.1.1](../../research/open-source-landscape.md#mapping-crdt-20261012)，该文档按仓库规则私有归档，不包含在公开 Git 提交中；公开来源继续保留在本目录 ADR 0004。

这些修订补齐文档要求，**尚未在参考模型或生产中实现/验证**。原18项测试不覆盖本次新增映射；待验场景见[验证说明](VALIDATION.md)。既有设计访谈与生产技术选型不因本次修订改变。
