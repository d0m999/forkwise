## 本地参考验证

发布前，在独立云端参考模型目录重新运行 Python 标准库命令 `python -m unittest discover -s test -v`，18 项通过。该目录的 Python 代码、测试与 SQL DDL 未随本次文档发布；仓库读者不能仅凭本目录复跑这些测试。此记录是本地参考验证摘要，不是 GitHub CI 结果或生产验收。

覆盖：40步历史和单调版本、人类撤销与 Agent 只读历史、编辑与拖动分域、丢失回执重启重试、失败事务无半写、命令幂等与权限、IME与旧ACK草稿保护、连续编辑分组、单父无环与成员移动、普通连线环与同对象端点限制、普通删除优先及容器端点冻结、正文独立复制与引用失效、资料快照复用、固定快照分页、完整响应字节预算、Unicode及未知块无损展开、权限变化游标失效、SQLite参考DDL创建。

未验证：真实编辑器和浏览器接线、媒体上传请求ticket与取消、生产权限服务、多线程或跨进程并发、旧数据迁移、生产性能、CRDT候选库、真实模型token消耗。没有运行仓库后端 TypeScript 检查、Vitest 或构建；文档发布没有改动运行时代码、配置或依赖，不能将18项参考测试等同于这些检查。

| 待验场景 | 必须观察到的结果 | 决策依据 |

### 附着图片裁剪与恢复待验场景

以下补齐评审 P2 的跨域场景，全部**待实现/待验证**，不计入原18项通过。详细写集和计算规则见[字段映射](docs/STORAGE-MAPPING.md#附着图片裁剪与恢复的原子闭包待实现)。

量化 fixture 固定目标世界锚点 T=(200,160)，并仅为此 fixture 使用图片可见框中心作为批注锚点；不将它定为全部类型的产品锚点规则。世界框记作 B=(x,y,width,height)，初始完整图 B=(100,100,200,120)、rotation=0、crop=(0,0,1,1)、offset=(0,0)。资源与目标身份保持不变。

| 待验操作 | 预期结果与证据 |
| --- | --- |
| 裁去左侧25%，应用crop=(0.25,0,0.75,1) | B=(150,100,150,120)，新中心=(225,160)，offset=(25,0)。crop、尺寸和offset同事务/同回执保存；不能保留offset=0而把左边读成125，也不写派生Pose.x/y。重读/重开保持此框，undo一次恢复初始三域，redo恢复裁剪结果 |
| 裁剪后已移动并横向拉伸，再恢复完整图 | 从crop=(0.25,0,0.75,1)、B=(350,200,300,120)、offset=(300,100)出发，按当前变换恢复B=(250,200,400,120)、offset=(250,100)。原可见区域仍占(350,200,300,120)，不退回裁剪前旧布局；恢复的crop/Pose/offset同一步保存及撤销，原图不改 |
| 中心对称裁剪，无需改offset | 新crop=(0.25,0.25,0.5,0.5)、B=(150,130,100,60)，中心仍为T，offset保持(0,0)。crop/尺寸仍原子保存，attachment只校验有效性与版本、不新增版本；恢复完整图同样检验依赖。已完整且无几何变化时再次恢复不写版本/历史 |
| 已有90°旋转或非等比拉伸后裁剪/恢复 | 依据当前crop、方向、比例与附着投影计算新世界范围，保留已可见像素位置和比例；必要offset与内容/尺寸原子提交，锚点定义不换。未变offset不被强制改写；UI与Agent同快照看到相同范围 |
| 完成前目标移动/增高/删除，或图片解除/重附着/另一次修改 | 依赖版本或附着状态失效，crop/Pose/offset全部不写，不产生半条历史/回执；保留可处理的预览/输入并重读，不能用旧世界框静默重放。自由图片计算后被并发附着也须拒绝旧操作，不补造关系 |
| 取消预览、保存失败/重试及提交期间分页读取 | 取消不写版本或历史，保存失败无半写；已成功的同commandId重试复用回执。一次提交只产生同次实际变化，读取不拼接新crop与旧offset；undo/redo保持原附着目标和原图身份 |
