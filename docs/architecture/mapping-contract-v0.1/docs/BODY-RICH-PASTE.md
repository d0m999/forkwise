# 正文富文粘贴：生产接口增补（#14）

本文记录 #14 的有限实现形状，不将参考契约其余提案改为已实现。代码、提交与私有实施记录分别承担实现和验证职责。

## 正文表示

所有格式继续通过既有 `body.edit.payload.blocks`、正文版本前置条件、可信 actor、同项目访问权限及统一历史保存，没有新增粘贴端点或数据库迁移。

- `code`：`id`、可选 `inlineId`、`text`、`language: string`、`wrap: boolean`。只存字面文字，不执行代码；此处仅支持围栏转换／导入后的基本阅读与字面输入。
- `table`：`id`、可选 `inlineId`、`header: boolean`、`rows: { text, marks? }[][]`。行列非空且矩形，单元格仅允许现有行内格式，链接沿用安全协议校验。导入内容只读展示并保留后方输入位置，行列和列宽编辑不属于本次增补。
- `pendingImage`：`id`、可选 `inlineId`、`name`、`mime`、`byteLength`、`base64`、`status: "unsupported"`。这是剪贴板字节的只读保留状态，不是已上传资产、媒体任务或可显示图片。字节长度与 base64 编码长度／填充须一致，图片 MIME 与字段集合均校验；不解码、不挂载图片资源、不网络取图。

新增形状按字段集合精确识别；带额外字段、不完整或无效的既有 JSON 仍按只读原件保留。其复制沿用 [BODY-BLOCK-COPY](BODY-BLOCK-COPY.md) 的服务端同项目不可变版本完整 JSON 校验，剪贴板 `readonlyIds` 不授予写权限。

每次文件图片读取／HTML 内嵌图片解析的字节上限为 512 KiB；文件异步粘贴路径还检查合并正文 JSON 的 UTF-8 字节数不超过 850000，预留既有 HTTP 1000000 字节请求边界。检查失败明确提示并保留原正文与剪贴板；通用保存失败仍沿用未确认草稿恢复，不伪称已保存。此限制未放宽原请求保护，也未提前实现媒体资产流程。

## 输入与粘贴事务

键入快捷仅检查当前连续输入范围；段首标记消费新输入的前缀，保留后方旧文字及格式。组合输入、光标移动、历史操作和粘贴结束当前触发范围。原触发文字先进入输入历史，转换为独立动作，一次撤销恢复完整触发原文，继续撤销按原输入分组回退。

默认顺序为代码内纯文本、同应用结构化内容、常见 HTML／已存在图片字节、纯文本。完整 Markdown 解析仅由明确菜单触发。纯文本按换行与空行保留。普通文字选区按文字范围替换；结构块复制的既有身份与层级边界不变。

HTML 在无浏览上下文的独立 document 的 inert template 中解析；原资源节点从不接入页面。输出只由允许的块和行内标记重建。脚本、事件、样式中的资源地址不执行；远程图片只保留可见链接。不能可靠保留的结构提示并保留纯文本和已有图片字节。

异步读取固定原正文和文字选区。内容变化、历史锁、组合输入或编辑器关闭使原操作失效，结果不能写到新的光标或卡片。链接工具也固定目标；单击仅预览地址，明确“打开链接”才导航，移除只移除链接标记。

## 投影与保真

表格文字用制表符与换行连接，代码保持原文字，待支持图片显示文件名和状态。UI 预览、Agent 的有界正文投影共用该文字投影；`detail` 仍提供同 snapshot 的完整 JSON 分块读取。完整序列化、历史和 SQLite 重开保留所有新形状及字节字段，摘要不替代原件。

公共回归入口：`backend/tests/mapping-rich-import*.test.ts`、`frontend/tests/markdown-paste-links.spec.ts`、`rich-paste.spec.ts`、`rich-input-boundaries.spec.ts`、`links.spec.ts`。浏览器事件、浏览器剪贴板 API、真实系统剪贴板与原生输入法分别记录证据，不能互相替代。
