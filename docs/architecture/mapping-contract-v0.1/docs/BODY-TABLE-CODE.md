# 简单表格与代码块编辑：生产接口增补（#15）

依据 D279–D283、D285 与 ADR0019/0026。沿用 #14 的 canonical table/code、`body.edit`、完整 Body JSON、权限、版本、幂等、observe 和统一历史；不新增端点、数据库迁移或编辑器引擎。本文件不把参考契约中的其他提案改为已实现，具体验证状态另见私有实施记录。

## 表格

`table` 保持 `id`、可选 `inlineId`、`header: boolean`、矩形非空 `rows: {text, marks?}[][]`，新增可选 `columnWidths: number[]`。列宽按列顺序，与列数相等；每项是有限 CSS px 数值，范围 48–2000。未设置时界面使用 160px 初值，不因打开、读取或窄面板而补写。增删列同步修改已设置的列宽；删行不修改列宽。

插入默认为 2 行 2 列。单元格只编辑已有行内格式和文字，不拥有子块身份或嵌套块；打开不重写单元格 JSON；未实际编辑的单元格在结构动作中保留原字段与 marks，DOM 的键序和格式合并不当作用户内容变化。粘入多段内容时保留文字、行内格式和换行，结构块采用其纯文投影。Enter 在单元格内换行；Tab/Shift+Tab 导航，首格 Shift+Tab 留在首格，末格 Tab 新增一行。Esc 退出输入焦点。行列删除按钮显示序号与受影响单元格数量，最后一行或列不能直接移除，整表删除使用块菜单。

首行表头、增加或删除行列、应用列宽、末格 Tab 新行各为一次结构动作，可一次撤销；列宽表单在明确应用时提交，输入数值的中间字符不成为历史。撤销导致原单元格消失时，明确提示并将实际焦点和选区定位到当前表格的首个单元格，工具栏显示同一实际位置；仅恢复选区不改写正文。宽表只在自己的块内横滚，不扩展正文横向宽度。显式操作可在表格下方插入普通段落。

## 代码

`code` 继续保存 `id`、可选 `inlineId`、字面 `text`、`language: string` 和 `wrap: boolean`。语言只作为元数据，不执行代码、不渲染 HTML/图表；纯文复制保留原字符、换行和缩进，不写正文或历史。默认语言为纯文本，wrap 关闭，已有语言值保留并可选择。

Tab 插入两个空格。Enter 保留光标前当前行的前导空白；⌘Enter/Ctrl+Enter 或显式按钮在下方插入普通段落。Esc 退出输入焦点，之后可继续 Tab 访问控件。文字转代码去除行内样式并保留文字与换行；代码转段落保留全部字面内容。菜单明确转换结果。代码内粘贴始终是块内纯文。

## 一致性与保全

输入法组合优先，历史请求期间包括嵌套单元格在内的输入路径只读。动作与 400ms/2s 保存批次继续分别处理，既有原卡身份、草稿、迟到 ACK、冲突和历史单一路由不变。

表格纯文以制表符分列、换行分行，单元格内换行保留；代码为原始 text。相邻正文块以换行分隔。UI 预览、Agent body 投影和剪贴板块复制使用现有投影；同 snapshot 的 detail 仍完整序列化全部 JSON。带额外字段、未知格式或不合法旧形状继续只读原件保全，不因本票识别列宽而丢弃未知字段。`pendingImage` 仍为 unsupported 字节保留，不作为真实媒体功能。
