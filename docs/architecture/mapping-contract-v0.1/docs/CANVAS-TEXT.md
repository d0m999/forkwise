# 独立文字生产契约增量

本文描述本票实际新增的 Mapping 与本机 Web 行为。目录内原 CONTRACT、GLOSSARY 和 ADR 含参考／提案状态；本增量不将其未实现字段宣称为生产能力。依据为 D383–401、D422、当前产品基线及父 #1 的本地执行规则。

## 对象、身份与版本

独立文字是 `kind: text` 的画布对象，不是卡片、正文块、材料或领域主张。内容仅为多行文字及局部 `bold`／六位十六进制 `color`；`fontSize`、`lineHeight: 1.5`、`align`、`widthMode` 和 `width` 属于整个对象。行内字号、图片、正文标题／列表／表格块和转卡均不接受。不设置独立文字的产品字数或 run 数量上限。HTTP 继续沿既有通用 1,000,000-byte 单请求资源边界，超限明确拒绝而不截断；该传输限制不代表短文字用途或自动转卡规则。

`id` 与 `item.id` 分别固定文字与画布姿态身份。移除保留身份墓碑，后续创建不可复用；撤销重做恢复相同身份。文字 `versionId` 与 `item.versionId` 独立，历史按实际改变的域恢复；文字编辑撤销保留后来独立移动的姿态。版本写入、项目修订、历史和原请求收据共用真实 SQLite 事务。

`item.createdOrder` 是创建时的项目修订序号，新卡片、文字和文字副本共同使用。旧卡片缺该字段时保留原读取顺序，排在新对象之前。它只支持当前共同创建顺序及选择呈现，不宣称已实现未来的完整跨类型层级菜单。纯卡片选择临时抬升并保持内部顺序，保留既有各卡操作菜单；文字及混合选择保持实际遮挡。文字工具只在总选区数为一时显示；混合选区隐藏文字与卡片操作栏。

## 命令闭包

| 命令             | expected                  | 实际写入                                                              |
| ---------------- | ------------------------- | --------------------------------------------------------------------- |
| `text.create`    | `null`                    | 新文字、独立 Pose、创建顺序及身份墓碑                                 |
| `text.edit`      | 文字版本                  | 完整内容与全部样式／宽度模式；Pose 不被旧内容覆盖                     |
| `text.move`      | Pose 版本                 | 仅 x/y；无位移 UI 不发请求                                            |
| `text.transform` | 文字＋Pose 版本           | 内容、统一字号与完整几何原子提交                                      |
| `text.delete`    | 文字＋Pose 版本           | 从当前投影移除，历史保留完整对象                                      |
| `text.copy`      | 文字＋Pose 版本           | 新独立身份，完整内容快照与宽度模式，x/y 各加24，新建置顶              |
| `text.layout`    | 文字＋Pose 版本           | 当前内容真实测量后的宽／高，保留 x/y，不产生独立历史步                |
| `canvas.move`    | 每个 item.id 的 Pose 版本 | 卡片与多个文字的 x/y 组成一个原子动作；任一目标缺失／版本冲突整批拒绝 |

所有命令沿既有项目与写权限校验。收据按原 `commandId` 与完整请求幂等；未知响应重试保持原键和原 payload。`textVersions` 回传本次确认的文字及姿态版本，后来输入仅沿已确认内容版本继续，不能用一次较新的 readback 冒充旧 ACK 覆盖的代际。

## 历史、空白与复制

放置和同一编辑组的连续首次输入合为一步。编辑内原生 undo／redo 只改文字输入；退出后使用项目历史。与首次创建同组的无变化 `text.edit` 也不拆开该组。清空已有内容后结束编辑的移除可一步撤销回清空前；新建未输入或仅空白结束也移除且可撤销。Esc 保留当前内容并结束，随后回选择工具。

测量只更新派生呈现，不额外占历史；紧邻创建／编辑的测量保留其同一步分组，并更新可重建的姿态投影。`canvas.move` 的卡片与文字变化保存在同一历史动作，撤销重做一次覆盖全部成员。全局历史仍沿用既有40步上限。

复制是画布菜单“生成文字副本”的独立副本，不接系统剪贴板。它不继承编辑会话或原对象身份，后来修改原件／副本互不影响；重开与 undo／redo 保持全部样式及宽度模式。系统剪贴板跨对象粘贴不作为本票已完成能力。

## 读取与变更观察

公共项目读取新增 `texts`。紧凑协议使用同一固定 snapshot／revision 的 `text-index` 与 `text-detail`：索引提供全部对象样式、宽度模式、Pose、runCount 与 `not_fetched`；详情把冻结文字版本序列化为按 Unicode code point 分割的 JSON 片段，可无损还原完整 runs。卡片 index 的 scope 仍只表示卡片，不以卡片空列表冒充画布没有其他对象。客户端将 `text-index` 与每个 `text-detail` 的首响应 snapshot／revision 分别和卡片 index 首响应交叉核对，再核版本、分片顺序及 runCount；任一不符则拒绝整份投影并提示重新读取。此为客户端防御合同，不表示普通后端已发生混读。

observe 明确报告 `text` 与 `pose` 域；删除包含两类身份。混合移动的 delta 报告全部实际改变的姿态，内容与样式保持原值。HTTP 与 MCP 继续走同一 Mapping 权限边界。

## 排版与输入

默认18px、1.5行高与自动上限320个画布单位沿 D385/D393 的当前参数。自动宽按真实文字增长至上限；左右把手转为固定宽且不改字号，固定宽不受320限制。四角沿对边锚点统一缩放字号与文字框，保留原宽度模式；自动模式的宽度上限也同比缩放。测量使用 DOM 实际 bounds 除当前画布 zoom，存为派生 Pose，初始受控节点尺寸与 Pose 一致。所有调节不压扁字形；字号与块对齐始终作用整个对象。 字形与换行在共同18px基准下排版，按对象统一字号等比呈现，避免改变实际CSS字号时字体度量重新换行。可见外框、把手与DOM测量使用缩放后的尺寸；固定宽直接保持已保存的排版宽度，不经内部基准宽度的舍入回写。内层新布局尚未同步到外框时不提交旧外框的派生Pose，允许的差仅为CSS亚像素舍入。

该调宽／角点适配沿 D399 采用已记录的 [AFFiNE 固定源码参考](../../../research/open-source-landscape.md#notion-与-affine-混合文字样式控件核对2026-10-11)及该文的文字 resize 索引；只借常规几何规则，不引入其完整富文本块容器，也不声称运行过 AFFiNE 上游测试或 GUI。

局部混合加粗不激活按钮，点击统一加粗；混合颜色保持通用颜色入口。只有光标时改粗／色只影响后续输入，重新定位后继承当地样式并同步工具栏。恢复 caret 后显式保留粗／色组合，避免设置颜色清掉刚选择的输入粗体。工具条在画布和视口内定位；颜色面板保留可访问范围。

Enter 为换行。IME composition 期间不提交半成品，Esc／外部点击的结束请求延后至 compositionend。普通外部单击保留修改并直接切选择；编辑控件不算外部。paste 与 drop 只取纯文本，不嵌图片或完整正文块；实际拖动样例来自本票自有同源 frame，合成 paste 不读取 OS 剪贴板。

## 保存与恢复

编辑文字沿400ms debounce／2s最长等待保存。每一代完整内容与原未确认命令存入本编辑器独立 owned 恢复记录；旧 ACK 只确认其提交代际，不能清掉保存期间后来输入。重载后由用户显式恢复，先原键重试未知请求，再提交后代。

整对象格式意图绑定显示时的文字版本；同目标排队后代只沿本队列真实 ACK 的文字版本继续，不能为旧完整 runs 借用 fresh read 的版本。调宽／四角变换同时绑定计算所依赖的文字与 Pose 版本，外部先改位置或内容时整次拒绝，不用新 Pose 版本提交旧完整几何。仅本机 `text.layout` 的原 expected 到真实 receipt Pose 因果链可推进手势依赖；文字版本仅沿与手势显示完整内容一致的本机格式原 expected 到真实 receipt 继续；外部文字或位置更新仍须冲突。

对象格式的有序队列同样保存原命令及后来的完整样式意图，显式恢复后保留排队字号／对齐／局部强调。本机 `text.transform` 的确切 expected→receipt 文字版本链同时保留该次完整 content 与 Pose；尚未生成请求的格式后代只把其真实 patch 叠到该确认内容上。已生成但 ACK 未知的原请求保持完整 payload 与原键，不以重读或后来格式重写。格式、测量和几何共享操作边界；历史、项目切换及离页检查等待尚未确认的文字工作。读回仅能更新原项目，顶部保存状态计入文字的等待、保存、错误与恢复。

等待本机格式队列结束后进入编辑，会话沿该目标原 expected 到真实 ACK 的完整内容、样式及文字版本继续，并重新核对项目及对象／item 身份。项目读回不为旧输入背书；真正外部正文或样式竞争仍按文字版本拒绝。

创建也在发送前以独立 owned 记录保存完整原命令、对象和项目身份；未知ACK的重试与重载后显式恢复均复用原请求，不重新放置替代。结束空白文字并发出删除后，编辑控件立即结束，未确认期间不再接受后续文字；原删除请求仍保留，未知结果重试不使原目标复活。

确定的版本冲突与未知结果分开：编辑、整对象格式和文字几何的真实409，以及目标已删的确定404，把完整本地意图与当前权威版本交给独立持久冲突记录；同一目标后来排队的完整样式一并保留，已拒请求不再原键循环重发。用户显式比较两份文字、样式和位置，选择生效前先将另一份以独立身份及24单位偏移保存为恢复副本。采用本地内容仍校验当前相应文字／姿态版本；选择当前版本不覆盖它。目标已删除只恢复为副本，不复活原身份。冲突选择的未知结果仍保留原完整创建／替换请求以重试；再次真实冲突须重新比较。

冲突交接先取得权威项目，再同步捕获同项目／同目标的队列边界与实际后代 patch，持久写入成功才退役已接管边界内的操作。后代格式 patch 叠到被拒请求或手势捕获的完整内容与几何上，不以旧 draft 的 width／widthMode 覆盖已确认的调宽或角点意图；选择保留我的移动且接管了内容时，以同一次 `text.transform` 校验文字＋Pose 并保存完整意图。副本操作保留点击时的冻结快照；后续原对象格式另以第二个新身份恢复副本保存，两份去向在 UI 明示并持久保留。每份恢复创建各自复用原未知请求，全部确认后才退役恢复记录并显示已保存。

移动／生成文字副本在 prepare 成功读取完整项目后，若已确定源不存在，或移动依赖的原 x/y 已被外部修改，在任何 mutation 发送前以捕获的完整本地快照进入同一持久冲突流程。成功交接才退役同目标队列、清除移动预览并发布已读取的权威投影；重载可显式恢复为新身份副本，已删源不复活。读取失败不视为确定删除或竞争，原队列继续保留；mutation 已发送但 ACK 未知仍保持原命令／原键，不以新 readback 重建旧请求。

混合 `canvas.move` 的确定409先将整组原命令及各成员已保存位置交给独立持久冲突记录，成功交接后退役已拒请求并清除整组预览。用户可重载后显式恢复，比较整组意图与已保存位置，再明确放弃本次移动；放弃读取当前权威位置并释放导航，不重新提交任一成员或以 fresh 版本背书旧位置。未知网络 ACK 继续保留原命令和原键，不进入确定拒绝的放弃流程。

尺寸把手支持方向键，Shift以10画布单位加快；左右只调宽，四角共用指针的等比计算、对角锚点及原子text.transform／undo。最小呈现宽度沿18px字号下20单位同比变化，短字符缩小时也保持比例；创作工具显式互斥，结束新文字回选择。工具颜色／对齐选项共享定义，但整对象与局部选区的应用回调分别保留。工具尺寸与间距以CSS变量令牌表示。

文字对象的可聚焦内容提供方向键平移入口，沿现有卡片每次10画布单位及统一历史边界，Enter可编辑；混合选择走同一原子canvas.move。文字输入及composition不触发平移，尺寸把手方向键仍只调尺寸。工具条边缘与锚点间距读取CSS令牌，当前实际值保持8px。
