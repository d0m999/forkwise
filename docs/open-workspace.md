# 开放工作台：本机第一张卡

本入口使用 ADR0011 已选择的 React Flow。现阶段支持项目创建、重命名、切换，以及普通卡片独立标题、简单正文和位置的 SQLite 自动保存。正文与位置可同时保存，互不覆盖。旧研究入口、原型及其数据库保持原样；不自动导入旧项目。本阶段提供最小拖动持久化，以及具明确项目编辑委托的调用者共用的 Mapping 写入口。完整摆放、吸附与多选（#8）、撤销（#4）、完整恢复（#5）和完整 Agent 产品交互（#38）仍待后续实施；不提供富文本或资料迁移。

## 安装与启动

需要 Node.js >=22.22.2。在仓库根目录安装锁定依赖：

```sh
npm --prefix frontend ci
npm --prefix backend ci
npm --prefix backend run build:workspace
```

选择一个新的绝对路径作为数据目录，再启动：

```sh
FORKWISE_DATA_DIR="$HOME/Library/Application Support/Forkwise/Open Workspace" npm --prefix backend run start:workspace
```

启动后，使用当前本机账户读取该目录的 `local-access.json`，在本机浏览器打开其中的 `url`。该文件仅本人可读（0600），数据目录仅本人可访问（0700）；启动不会自动放宽或更改已有权限。URL 中的临时凭证通过片段传给页面，换取 HttpOnly 会话后立即从地址栏清除；启动日志不打印凭证。直接访问裸地址不会获得项目访问权。关闭进程后，以**相同目录**启动即可重开。端口占用时显式设置 `FORKWISE_PORT`。本入口要求独立目录，拒绝旧资料目录、未知格式、符号链接、多硬链接文件及缺失主库的残留 WAL/SHM；没有自动搬运、覆盖或修复原件操作。

旧 `npm --prefix backend start` / 8787 入口没有改变。不要用旧启动命令验证新卡片，也不要把用户旧 `.data` 指定为本入口目录。新入口的构建或启动失败不会替换旧入口。

## 使用

- 「新建研究」直接打开空画布，顶部项目标签切换项目，「重命名」单独改项目名称。
- 「见岔」展开紧凑项目导航，可固定。项目编号用于区分同名项目。
- 点击底部「卡片」，再点击画布放置；键盘聚焦「卡片」后按 Enter 在可见画布中央创建。
- 卡片标题可独立编辑，Enter 完成、Shift+Enter 换行、Esc 保留。中文组合输入结束前不触发完成。
- 拖动卡片的非编辑区域可保存位置；键盘聚焦卡片的移动按钮后，用方向键调整位置。写正文时可以移动卡片，两类保存独立校验版本。
- 「编辑正文」打开右侧简单正文输入。编辑自动保存；只有 SQLite 写入及回读成功才显示「已保存到本机」。未保存时离开页面有浏览器提示；保存失败保留当前输入。标题和正文分别保留待确认输入；旧保存回执不会清掉较新的输入。切项目须等待最新输入确认，目标项目加载期间的新输入也先保存到原项目。
- 同一标题、正文或位置被另一调用者更新时，保留本地输入并显示已保存内容或位置；明确确认后才重试保存。确认前对方再次更新时，会再次提示冲突，不直接覆盖尚未确认的新版本。

当前研究数据只写入专用目录的 `workspace.sqlite` 及其 WAL/SHM；本机启动凭证独立写入同目录的 `local-access.json`。卡片、正文、文本块和画布项有独立稳定身份；标题、正文与位置分别版本化，正文和位置保留独立不可变版本。`Mapping.read/execute/observe` 是本阶段唯一业务读写入口，UI 与可信调用者共用 `execute`：先验证会话身份、项目权限和编辑委托，不能通过请求内容自报 human 获取权限。具明确项目编辑委托的 Agent 可调用该写入口；这不包含完整 Agent 授权管理或交互界面。版本、历史、成功回执和变更同事务保存，跨重启原命令重试不会重复写入。没有使用 localStorage 保存卡片，没有遥测或模型调用。版本记录与未来的40步撤销功能是不同能力。

## 验证

```sh
npm --prefix backend run check
npm --prefix backend test
npm --prefix backend run build
npm --prefix frontend exec -- playwright test
```

浏览器测试请从 `frontend` 执行 `npx playwright test`，先构建。它自动分配回环端口、新建临时目录、重启正式构建后的服务，并创建全新浏览器上下文；不操作用户浏览器配置或旧存档。可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 使用已安装 Chromium，测试不修改浏览器二进制权限。否则按 Playwright 的标准方式安装测试 Chromium。

浏览器自动输入中文文字不等于真实系统输入法验收；此项应单独记录。完整开放画布能力按后续工单推进，不能从第一张卡的保存成功推定整个引擎适配完成。
