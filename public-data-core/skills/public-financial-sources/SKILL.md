---
name: public-financial-sources
description: 查询维护目录内的公开金融数据，核对披露版本、历史已知日期与财务口径，调用独立数据核心保留本机快照。适用于 SEC 原始数据获取与复核。
---

通过本包 `src/cli.js` 或 SDK 获取数据。先运行 `catalog` 检查实际覆盖和访问限制；支持范围以目录及适配器返回为准。包可独立运行，不依赖 Forkwise 数据库或画布。

用户明确主体和所需指标后，核对 CIK、taxonomy、tag、单位及研究截止日期。CLI 的 `sec` 参数顺序见 `--help`。联网前使用本人提供的 `SEC_USER_AGENT` 联系信息；缺失时报告配置缺口，不编造邮箱。原始快照与请求回执放在使用者自己的 `FORKWISE_DATA_CACHE`，不得写进公开仓库。

结果逐条保留 accession、原始数字、业务期间、披露日期、获取时间、适配器版本与 JSON Pointer。`publishedOn` 只有日期精度，不能当作具体时刻。历史研究使用 `knownByDate` 过滤当日及此前披露，今日获取时间另记；需要精确到当时某一时刻时须补充原始申报时间。

`duration_unclassified` 表示尚未分清单季与累计，须回查报表后才能转为计算输入。`fp=Q2` 或 `frame` 不能单独证明是第二季度单季值。同期间不同 accession 都保留，不能静默只取最新值。超出安全数值精度的原始数字保留字符串与锚点，计算值为空；缺失不填零。

需要将较大 JSON 交给模型时，读取 [SDK 取材接口](../../README.md)：`companyfacts` 使用 `selectCompanyFactPassages`，`submissions` 使用 `selectSubmissionPassages`。提供明确检索词和字符预算，保留所有返回片段、结构角色、记录缺口与覆盖说明；使用对应 `validate*Passages` 对固定快照复核后，再交给模型。CLI `sec` 获取完整快照，不提供结构取材命令。

申报索引中的同一 `recordPointer` 表示同一行，须一并读取申报编号、类型、披露日期、报告期间日期和文件名；修订版单独保存。`documentUrl` 是由索引构造的导航入口，`historyFileCount` 是列出的历史文件数，分别报告正文、附件和历史文件是否实际取得。索引只能支持其元数据，核对营收等正文主张需另取相应材料。`reportDate` 不足以确定起始日或单季口径，接收时间保留原值；精确历史研究仍须核对原始材料时间。

先验证引用的快照指纹与 JSON Pointer，再将有权使用的材料交给目标研究工具。取到原始数据不表示已经支持某条主张，不改写个人立场或条件确认。SDK 的 `compareFacts` 只检查基础口径；调用方仍须核对期间、披露版本以及自己的计算白名单。

访问被拒绝、资料不存在、限流、数值缺失与口径不可比分别说明。适配器在受限访问时停止，不尝试绕过；重试复用已保存快照或按原请求显式刷新。成功标准是能回查原始披露及所用版本；合成测试通过不能写成真实来源覆盖验收。
